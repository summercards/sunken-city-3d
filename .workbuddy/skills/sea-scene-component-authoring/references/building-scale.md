# 与正式阳光房一致的建筑尺度

> 2026-11-02用户修订：新制作按SKILL.md内一位小数基准执行（大尺寸米、小尺寸厘米）；下表及倒角高精度值保留为v008历史测量，不作为新制作的多位小数目标。现有模型不因取整改变。

适用于sea海上主场景中同族水上功能建筑、水下观赏楼及海下基座。两类共用SKILL.md的一位小数风格数值，先按building_class加载above-water.md或underwater-scenery.md职责差异；水线偏移仅适用于水上临水平台，独立海底场景排除。基准是正式`solar_cabin`的v008运行装配，2026-10-31由Godot探针量取真实MultiMesh网格及逐实例世界变换；不是Blender未缩放尺寸或凭截图估算。机器数值和来源见[building_scale.json](building_scale.json)，项目证据为`docs/development/2026-10-31_sunroom_dimension_probe.json`。

### 倒角档位

源文件里没有 BEVEL 修改器（导出前已求值），下列宽度由 `probe_bevel_metrics.py` 反推：33 个单体重建同尺寸立方体，三角数 188 唯一匹配 3 段，再按面宽线性解宽。全部段数 = 3。

| 构件 | 源宽 (m) | 运行时 (m) |
|---|---:|---:|
| 屋顶压顶 | 0.095 | 0.1639 |
| 上层小间 | 0.080 | 0.1380 |
| 女儿墙 | 0.070 | 0.1208 |
| 主柱 | 0.055 | 0.0949 |
| 主平台板 / 栈桥板 | 0.0546 | 0.0941 |
| 廊返 | 0.045 | 0.0776 |
| 棚柱 | 0.032 | 0.0552 |
| 露台板 | 0.0263 | 0.0454 |
| 混凝土条 | 0.0257 | 0.0443 |
| 灯罩 | 0.025 | 0.0431 |

取值规则：`源宽 = k × 最小边长`，结构件 `k ∈ [0.10, 0.30]`，薄板 `k ≈ 0.43`，且**任何倒角不得超过板厚的 0.5 倍**（主平台板 0.0546×2=0.1092，板厚 0.1275，余量 0.019）。同族新件取 0.055 主档；小件 0.02–0.035；细杆 0.008。

完整尺寸表、门窗包络与复现命令见 [阳光房尺寸与倒角基准](../../../../docs/standards/阳光房尺寸与倒角基准.md)。

新造型保持统一尺度与结构感；长宽和屋顶样式可设计，不要求复制阳光房外形。无门窗的建筑只引用门框标准作为比例参照，不为满足表格擅自增加门窗。净高与层高分别记录；斜屋顶、设备高度、女儿墙不计作新一层净高。圆角、板缝、木色也应与阳光房同级，避免细针柱、薄皮木板或过密地板条造成另一套风格。

运行米制以Godot最终网格与逐实例变换为准。`sunny_bloom_visual.gd`会按组件分组装成MultiMesh；`mesh.get_aabb()`本身不含每个实例的倍率，使用`global_transform * instance_transform * local_aabb`。只采`Models/太阳能木屋/太阳能木屋-海上区域`，避免把海下基座同名wall_pier混入。底层柱、上层装饰柱、长侧连墙件分别筛选，不能把整个合并包围盒叫柱截面。

若正式阳光房换版，用`python -X utf8 scripts/run_verification.py building-scale-reference --label sunroom-scale-reference`重新采集，核对实例清单哈希和稳定组件来源，再更新机器表及这份说明。所有运行探针走统一runner隔离用户数据；不要直接跑玩家档。对新资产核查实际木板宽厚、主柱截面、净高和楼板厚，保存重开后再比较；运行图将新建筑与阳光房同屏核对，不凭独立棚拍认定风格统一。
