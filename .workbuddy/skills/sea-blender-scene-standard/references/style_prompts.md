# sea 风格提示词库

用途：①生成/深化参考图；②向 Blender MCP 或建模助手描述目标；③复核某个组件是否跑偏。
用法：先选模板，替换 `<>` 占位，务必保留"禁"一栏；产出的图或几何要与 `SKILL.md §2.4` 的对应表挂上钩。

## 0. 全局锚句（任何提示词都该带）

```text
治愈系卡通写实、低饱和粉彩、厚实体量、柔和日光、边缘圆润。
cozy cartoon-realism, low-saturation pastel, chunky volumes, thick rounded edges, soft daylight.
```

## 1. 整体套件参考图

```text
主题：海上一座可居住的小屋群，位于平静浅海水面，栈桥连接主屋与前平台。
风格：治愈系卡通写实、低饱和粉彩（奶白/暖米白/浅沙/暖棕/海蓝/薄荷绿/珊瑚粉）、厚实体量、柔和日光。
体量：主屋双层错落、屋顶小间独立、单坡太阳能门廊、全宽木平台、双列栈桥；所有体量边缘厚倒角、圆润但结构清晰。
材质：奶白哑光墙漆带轻微颗粒；暖棕木铺板，纹理顺板方向；木色深浅轻微错落；海蓝只用于窗与点缀；珊瑚粉/赭黄用于花与小件焦点。
设施：厚圆角太阳能板 2 块、黄白条纹圆边遮阳篷、窗洞 4–6 个、木柱带绳圈、轮胎护栏、吊灯、躺椅与箱子。
植物：饱满圆润的叶簇与花团，花色 2–3 种，花朵朝上或斜上方；藤蔓从檐口自然垂落，长度长短不一。
光照：正午偏侧天光、柔和接触阴影、低对比、略俯视三分之四角度、50mm 等效。
禁：锈蚀破败、霓虹、金属紫、镜面反射、冷灰蓝主色、镂空雕花、薄片植物、杂乱小件、赛博/工业感。
```

## 2. 单体组件深化

```text

风格：奶油白哑光、圆润厚倒角、无锐边、无金属反光。
禁：改变整体轮廓、重排摆位、合并网格、新增材质球、平滑着色代替倒角。
```

## 3. 花草植被

```text
对象：<花团 / 叶簇 / 藤蔓 / 棕榈>，用于 sea 海上小屋的装饰。
形体：饱满圆润，少量大叶、成簇花团；花瓣为闭合有厚度的曲面（0.02–0.04 米），朝上或斜上方随机倾斜；叶片有中脉厚度 0.015–0.03 米，叶簇 10×6 分段球面，大花瓣 12×8。
颜色：粉红、白、珊瑚、薄荷绿，从公共色板取格，不新建色。
摆放：从檐口、栏杆、盆口自然垂落，长短错落；不与墙、盆、太阳能板焊在一起。
禁：单面片、锯齿裂叶、茎叶穿模、塑料感高光、颜色过饱和。
```

## 4. 材质与配色复核

```text
复核对象：<组件>。
要求：颜色只由 PaletteUV 单格决定；材质只用 SEA_Matte / SEA_Metal / SEA_Gloss / SEA_Emission；
哑光占主，金属面积不超过 10%，清漆只用于玻璃，自发光单独网格且不超过 5% 面积。

禁：为单个颜色新建材质球、把亮色当主色、紫金配色、金属度做主调。
```

## 6. 描述跑偏时的修正词

| 现象 | 加什么 |
|---|---|
| 出来太扁平 | "厚实体量、板材 ≥0.18 米、体块分面清晰、membrane 不要" |
| 太锐利 / 像塑料玩具 | "所有硬边 0.02–0.05 米实体倒角、圆润转折、保留平面细节" |
| 太灰脏 | "提高天光、降低对比、奶油白为主色、暗部保留 30% 亮度" |
| 太花 | "主色 2–3 种、焦点色面积 ≤10%、其余走同族浅深" |
| 植物像纸 | "花瓣闭合有厚度、叶簇饱满成球、朝光面亮背面稍暗" |
| 细节太碎 | "统一为少量大块面、删除螺钉与栅线级细节、保留轮廓与倒角" |

## 7. 提示词进计划

落图或落模型后，把命中的 3–6 条写进 `component_plan.json.visual_priorities`，用**可验收的表述**（例："板材厚度 ≥0.16 米并带 L1 倒角"），不要写"看起来柔和"。验收时逐条对照，不靠回忆。
