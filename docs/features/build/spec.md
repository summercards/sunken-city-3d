## 功能目的与边界

正式或规划入口：建造页前往世界施工牌交付。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-BUILD-R01 | 建造费用和前置条件检查通过后才扣料开工，走开或关闭面板不停止施工。 |
| SEA-BUILD-R02 | 等级只在工期结束时增加；满级、材料不足、已施工时拒绝重复开工。 |
| SEA-BUILD-R03 | 升级必须有可见场景反馈，保留 GDD 对木屋、农场、绞盘站成长的目标。 |
| SEA-BUILD-R04 | 施工服务不读取全局或场景树；重复开工不能重复扣费，剩余工期由本模块快照恢复。 |

## 4. 建筑与场景成长表现

### 4.1 太阳能木屋

- **Lv.1：** 破旧木屋、基础码头、少量储物空间。
- **Lv.2：** 屋顶出现花盆和暖灯，居民入住，解锁更多种植位。
- **Lv.3：** 增加屋顶生活区、晾衣绳、小桥或邻接平台，成为聚落中心。

### 4.2 屋顶农场

- **Lv.1：** 修复两格农田，种植基础蔬菜。
- **Lv.2：** 增加种植箱和热带植物，产量提升。
- **Lv.3：** 形成完整屋顶温室或花园，解锁更高价值作物。

### 4.3 绞盘打捞站

- **Lv.1：** 修好绞盘和基础吊钩，可打捞漂流物。
- **Lv.2：** 增加分类台和储物架，打捞效率提升。
- **Lv.3：** 出现悬臂吊车和工作灯，可打捞特殊零件。

### 4.4 水上码头与船只

- **Lv.1：** 初始木船，只能往返附近屋顶。
- **Lv.2：** 加装帆具或更稳定的船体，开放远海沉没街町。
- **Lv.3：** 增加货舱、打捞工具和更远航线，连接新的区域群落。

### 4.5 场景反馈要求

每次升级至少提供以下三类反馈中的两类：

1. **模型变化：** 建筑、植物、桥、灯、船体或设施本身发生变化。
2. **生活变化：** 居民、灯光、晾晒物、风铃、花盆、船只或小动物出现。
3. **功能变化：** 新资源、新种植位、新航线、新建筑或新交易选项解锁。
