## 功能目的与边界

正式或规划入口：海面、岸线、水下切换和滤镜面板。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-OCEAN-R01 | 波形与船浮动采样一致，岸线、水深吸收、泡沫和船尾迹按各自渲染契约工作。 |
| SEA-OCEAN-R02 | 渲染后端差异显式处理；逻辑测试不能代替真实渲染图像检查。 |
| SEA-OCEAN-R03 | 运行材质使用稳定路径，调参不覆盖制作源和布局。 |
| SEA-OCEAN-R04 | 白色水线采用圆润的低频轮廓与多圈渐细的卡通开放波纹弧线，环境与建筑光影采用半兰伯特柔和过渡与清晰投射阴影；透明交互圆盘、标记圆环不得作为岸线发射源。 |
| SEA-OCEAN-R05 | 水与物体的交接带单独由固定水位距离场驱动（移植生产版卡通水面的 ContactFoam）：米制水线 + 条纹侵蚀泡沫，具备出生、保持、退去三段生命周期；条带纹理不可用时退回程序外推环；水线宽度必须大于距离图 texel 才允许签署可见。 |
| SEA-OCEAN-R06 | 水面自发光合成必须保留俯视视角下的立体读法：从上方看时海面须能读出水在起伏（明暗带 + 浪脊线），不得呈现为一张平涂色纸；该层只允许改颜色，不得改动顶点位移、共享波场、船的吃水或岸线距离图。 |
| SEA-OCEAN-R07 | 出厂水色以可测量的像素目标定版，不以目测为准：等距俯视开阔水面的绿通道均值与参考帧相差不超过 4/255，通道标准差不超过 ±1.5；调色参数列入 P 面板并在 `water.tres` 中记录可复现值。 |
| SEA-OCEAN-R08 | 调色面板（P 键「滤镜 / 水面」页）打开时不得在被调画的画面上叠加任何压暗、去色或色偏的屏幕遮罩；该面板仍算模态（世界浮层收起、交互拦住），只是不铺遮罩。其余面板的遮罩行为不变。 |
| SEA-OCEAN-R09 | P 面板「光照」页必须能改环境与太阳两组参数，且与画面同源：环境项写 `WorldEnvironment` 的 `Environment`（环境光能量/颜色/天空占比、天空亮度、泛光开关与强度/光晕/阈值、环境遮蔽开关/强度/半径/受光、雾开关/颜色/受光/起止/曲率/天空间距），太阳项写 `World/Lights/Sun`（强度、颜色、角径、高度角、方位角、阴影开关/浓度/模糊/偏移/法线偏移/距离）。范围必须包住 `world_env.tres` 与 `scenes/main.tscn` 的出厂值；朝向以相对海平面的高度角与方位角表达，两轴互不覆盖。改值排他、不另立第二处真相；存档写在 `user://filter.cfg` 的 `[environment]` / `[sun]` 段，且不得冲掉同文件里的 `[filter]`。 |
| SEA-OCEAN-R10 | 水下的沉没建筑与海床必须能看见「阳光透过水面」形成的焦散光斑，且光斑属于水下几何体：水面移动时光斑不得跟着漂，开阔水面上不得出现光斑。两套水面方案都要有，参数进 P 面板「水面」页的「水下光斑」组（开关、颜色、强度、密度、速度、细纹、浅端起始、深端淡出）。 |

## 当前实现与待完成边界

保留拆分前水面修改；跨后端与目标设备仍需专项验证。

R09 的「光照」页只覆盖场景当前实际用到的属性。写到一半就要换光照模型的项（`ambient_light_source` / `reflected_light_source` / `tonemap_mode` / `fog_mode`）刻意不进面板：它们不是调参，改了等于换一套渲染模型，滑块表达不了这件事。体积雾、SDFGI、SSIL、SSR 同理 —— 项目没启用，列出来只是空转。

现有规则继续运行；独立文档、账本和目录归位不代表所有行为已经独立测试，也不代表全部原始目标已实现。阶段事实以本功能账本为准。
