| 条款 ID | 目标规则 / 应验证的行为 |

| SEA-RESIDENT-R01 | 住宅成长应带来居民入住与生活表现。 |
| SEA-RESIDENT-R02 | 居民身份与订单客人可关联，日常路线、对话和关系需独立状态所有者。 |
