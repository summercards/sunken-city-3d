设计修订：r1（2026-10-23 工程拆分，未更改玩法数值）。所属系统：世界。
范围来源：主文档保留的全局设计、拆分前文档与当前代码核对；下面明确区分目标与实现边界。

## 功能目的与边界

正式或规划入口：主场景 World/Zones。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

| SEA-WORLD-R07 | 装配保留建筑和植物及摆件的独立维护边界；纯视觉组件不进入船只阻挡或岸线生成。旧荷叶仅在与原烘焙三角形逐点匹配时退役，不按包围盒删除。 |
