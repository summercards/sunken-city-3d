# SEA-BUILDING · 海上自由建造与DIY

[主文档](../../../GDD_V1.0.md#sea-building) · [独立账本](ledger.md)

设计修订：r3，2026-10-30。按用户明确要求替代初阶“两圈/24新板/仅岸上施工”方案。海面上的实际建筑占地、泊位、船体和摆件约束决定能否建造；不设玩法地图边界、扩建圈数、平台必须相连或54实例数量上限。允许从家园接板，也允许乘船在远处建立独立平台。

本功能独立于SEA-BUILD固定建筑升级。BuildingService唯一拥有布局；BuildingWorld投影模型、行走面与地格；BuildingBoundary接收空间/状态查询；BuildingAccess派生海上施工点与登陆点；BuildingController和BuildingBook只展示和发送命令。材料由Inventory、作物与生长由Farm唯一写入。

## 操作与空间契约

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R16 | 固定六格、DIY标准/小型培养土及各阶段蔬菜均不阻挡人物，玩家可直接踩踏；导航/胶囊保留脚下木面，不生成种植占地洞口墙。承载、重叠、施工预留和搬移/拆回规则保留；经过不浇水、不收获、不损坏作物，站在种植区可保存恢复。种植配方显式blocks_actor=false，未来实心家具可声明true；固定种植格只有明确元数据声明才参与阻挡。 |

建造手册→选择木板/标准培养土/小型培养土→移动鼠标查看红绿虚影及原因→R旋转、Shift精细→点击接近并开工。岸上远处无可达工地时应先乘船；船上可选独立海面基础。右键回手册，Esc逐级取消选中的搬移/建造模式；退出已付款施工继续。

地图没有人为圈数限制，仍必须遵守真实占地。角色不能隔海遥控施工；独立平台先乘船到旁边建造，完工后从外露边登陆。原六格是新局已拥有的种植区，也是接板起点；固定与DIY种植格在每次布局同步后使用同一套格内/侧边操作点，业务和初始状态归SEA-FARM-R12。新DIY培养土放在完工木面并集上，不穿入原有箱体。

没有“拆除回退一格”的隐式业务：每次拆回都保留材料与状态原子性；已种作物不由建造系统收割、退种或清空。已有历史布局不强制通过新布局安全门禁，但新修改不得扩大其不安全程度。

## 实现与扩展入口

- Catalog：配方、几何、承载并集与技术布局字节预算；Service：布局/索引、候选、can_place/begin/tick、can_move/move、can_remove/remove、快照。
- Space：并集外边缘、角色宽度、稀疏连通分量与操作点；Boundary：实际世界占地、泊位、角色、作物拒绝及候选布局检查。
- World：表现、FarmField登记、行走/船阻挡/水线派生；搬移更新原节点，避免注销地格清作物。
- Access：船上工地点、动态登陆点与图标；Controller/Book：精细放置、管理与原因反馈；Main仅装配端口和既有导航/角色流程。
- 扩展资格/世界空间/容量策略通过configure注入，不让规则回读Economy或Main。未来新物件按role选择投影与交互适配，不改既有实例ID含义。

## 2026-10-31 平台只有一类，框架靠连接体

用户实测指出三种“板”行为不一致：拼接木板能接、走得过去；4×4 与 2×4 浮台拼不上，还会隔一段缝。根因是浮台按世界 2 米网格自由吸附、贴边候选又受 1.45 米光标半径限制，实际落不到旧板边上。本轮把平台收敛成一类，拼接能力由结构规则派生，不再单独维护一套“海面网格”。

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R22 | 拼接木板、4×4浮台、2×4浮台同属平台类，共用一套贴边拼接、承载、行走、水线与存档规则；框架件与摆件是另一类，必须落在完工承载面上并满足挂点。平台吸附以**边对齐**求解：先把候选一条边与已有承载面某条边贴合，再沿该边滑动，使候选自身的一条边与邻板角点共线；齐平候选优先于自由位置，光标到矩形的距离（而非到中心）决定取舍，因此4米浮台也能在板边被命中。相邻两平台共边长度须≥0.6米才算相连（大于角色直径0.44米），仅有角接触不算。接缝不内收，角色可跨缝行走；拼不上时给出明确原因而不是悄悄错开。岸上不能隔空起板：新平台必须与已有承载面有一条真实接缝，或乘船在该处海面另起独立起点（船是运料的连接体）。旧档中已存在的孤立平台照常读档、照常拆除，新门禁只约束新开工，不追溯破坏既有布局。 |

验收证据：[拼接专项](../../development/2026-10-31_platform_join_classes.md)。

## 2026-11-01 固定浮台的水下底座不再挡住扩建

现场反馈：浅水养殖台三处新木板全部报「无法拼接」，鼠标贴近平台边缘时提示「这里有既有建筑」。排查发现那不是别人的建筑，而是这块平台自己的水下底座。

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R25 | 建造判定的「既有建筑」障碍只应来自**其他**区块的地面与海上结构，不得包含当前固定平台自身的水下底座。派生实现要点：固定底座从水面线往下沉了十几米，它的水面阻挡矩形与平台轮廓等大；木板网格（2.15×2.575 米）与平台轮廓（6.45×5.15 米）不同步，贴着平台接的新格子必然与底座矩形重叠约 0.2 米，若不排除就等于四面封死扩建。排除口径以「阻挡矩形与固定平台轮廓相交」为准，只放行与平台自身的重叠，远处区块、海上浮店与其他结构照旧拦截。排除后仍须保证：原有平台本体不可被新板覆盖（仍报「这里是原有平台」）；泊位侧的格子继续拒绝，但原因必须说清是「泊位与上下船通道」，不能再说成「既有建筑」。 |

验收证据：[底座阻挡修复](../../development/2026-11-01_energy_fishery_and_join.md)（`building-base-neighbors` 28 项 0 失败）。已知不属缺陷：船正停在泊位时，泊位旁那一格仍会提示「请让船离开施工范围」，把船开走即可。

## 2026-11-02 旧布局续建与管理模式反馈

旧档保留原坐标，不把历史独立浮台重新吸回网格。R02/R22补充：拼接木板优先保留合法旧网格；网格不能与附近浮台贴边时，使用相同的边对齐求解，按实际矩形检查重叠及至少0.6米接缝。新木板可用显式坐标，仍保留尺寸、费用、工期和岸上必须连接的规则；远处海面光标不吸回岸边。只有完工平台提供新建连接。

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R26 | 搬移/拆回按钮点击后进入持续可见的对应模式，显示模式名、左键步骤、返回手册按钮与Esc提示；不在施工区时说明需前往自建平台或乘船靠近，不因资格拒绝而无反馈。管理选取按镜头射线与组件三维占地求交，支持点击高构件主体及二层物件；目标有清楚轮廓、名称及具体拒绝原因。固定设施、不可搬移的平台、施工中、有作物、承载物、角色所在板和通路保护仍有效。空处点击明确提示选择自建物件，成功拆回仅退款一次。 |
