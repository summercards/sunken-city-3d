# SEA-BUILDING · 海上自由建造与DIY

[主文档](../../../GDD_V1.0.md#sea-building) · [独立账本](ledger.md)

设计修订：r2，2026-10-29。按用户明确要求替代初阶“两圈/24新板/仅岸上施工”方案。海面上的实际建筑占地、泊位、船体和摆件约束决定能否建造；不设玩法地图边界、扩建圈数、平台必须相连或54实例数量上限。允许从家园接板，也允许乘船在远处建立独立平台。

本功能独立于SEA-BUILD固定建筑升级。BuildingService唯一拥有布局；BuildingWorld投影模型、行走面与地格；BuildingBoundary接收空间/状态查询；BuildingAccess派生海上施工点与登陆点；BuildingController和BuildingBook只展示和发送命令。材料由Inventory、作物与生长由Farm唯一写入。

## 设计条款与验收

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R01 | 右上建造手册展示三种配方、材料/工期、搬移和拆回入口，说明无固定圈数、可乘船开辟独立平台、精细摆位与完整拒绝原因。退出不穿透触发航行/种植。 |
| SEA-BUILDING-R02 | 木板可放在任何无实际建筑阻挡的海面，位置按世界基准网格吸附，支持有符号网格坐标、四向拼接和不相连的独立基础；不扫描固定地图矩形。原有六格木面不可重叠或拆回。建筑、水面实体障碍、保留泊位及当前船体占地禁止重叠；西侧只保护具体泊位通道，不再整列禁建。不以水下纯装饰、出生补给区或旧航区矩形作为建造边界。 |
| SEA-BUILDING-R03 | 木板6木板/3秒；标准培养土3木板+2土壤/4秒；小型培养土2木板+1土壤/3秒。预览、接近、取消均不收费；实际开工重验后一次原子扣费，占地立即预留，计时完才开放行走/种植。可同时施工多处；暂停冻结，关手册/离开继续，离线不推进。 |
| SEA-BUILDING-R04 | DIY摆件在全部完工新木板的并集上自由摆位，可跨板缝、同一板上多件；底面完整落在承载面内，外缘留4厘米，摆件间留2厘米，不压角色。默认0.1米吸附，Shift精细到0.01米，R按90度旋转。靠边不足0.4米可吸回合法点，精细模式使用对应细步长。实际提交不强制重舍入旧档坐标。 |
| SEA-BUILDING-R05 | 开工/完工/搬移/拆回统一重建占用、行走、船阻挡、水线和操作点。平台并集外缘按角色躯干半宽0.22米内收；只对明确blocks_actor的实体扣除同半径余量，种植区按R16可踩踏，不从甲板挖洞。拼缝不内收；拆板和阻挡物不得破坏已有连接、角色落脚点及操作位置，已有布局可读，不静默删作物。 |
| SEA-BUILDING-R06 | 布局v1嵌入根快照v4，保存稳定ID、配方、网格/位置、旋转、主支撑和剩余工期。不再54实例封顶；结构校验与放置共用几何规则，所有支撑板先校验，再校验摆件，不依赖创建顺序。旧v0–v3根档迁为空布局；旧v4精确坐标照读。整份候选布局/角色/船验证后，按布局→动态地格→Farm→角色船恢复，不重复收费。旧档贴板边站位在读档时就近移入安全行走面。 |
| SEA-BUILDING-R07 | 纯规则无Autoload/Main/UI/场景树依赖。资格、支付、退款、世界空间、候选布局和存档容量经注入端口交接，查询返回副本。开工/搬移/拆回有提交锁，重复点击、事件回调重入和拒绝均不产生额外收费或部分变更。 |
| SEA-BUILDING-R08 | 木板顶面世界Y=1.48米，尺寸2.15×2.575米；厚0.50米向下到Y=0.98米，低于基准水面1.12米。新板延续同一水线。标准培养土底面1.794×1.575米，小型0.9×1.0米；复用同一外观，尺寸由配方定义。 |
| SEA-BUILDING-R09 | 施工条92×8px自绘，暖棕轨道、暖金填充，不靠ProgressBar内容边距撑高；预览和赶路没有假施工进度。海面局部泡沫矩形先合并，24槽仅是近景着色预算，不是平台实例上限；全部木板仍参与布局、行走、船阻挡和存档。 |
| SEA-BUILDING-R10 | 确认后先到工地：岸上走到可达边缘，船上航行到目标旁合法水面；距离落脚目标≤0.8米且停止后才开工。等待预算随路程增加，基础8秒；取消/睡觉/读档清意图。绿色预览需同时满足放置、材料和实际施工点可达性，确认/到位再次校验，失败说明原因。船上只改变施工方式，不放宽建筑/船体/承载检查。 |
| SEA-BUILDING-R11 | 搬移仅限已完工DIY摆件：先选择实例，再选位置/旋转；Esc撤销选择、原物不变。成功保留实例ID、plot_id、作物、浇水、生长和收获次数，不收费也不重建农场状态。木板暂不搬移，可在安全拆回后另建。原场景固定设施与原六格不纳入DIY搬移。 |
| SEA-BUILDING-R12 | 拆回仅限本模块已完工木板或空种植区；有作物先收获，施工中不拆，原场景不拆。木板上有摆件（包括跨板占地）、角色站着、属于当前上下船落点或拆后切断既有通路时拒绝；摆件不能连带删除。成功全额退回该配方材料；背包放不下整笔退款时保留物件和全部材料数量，不部分退款。 |
| SEA-BUILDING-R13 | 每块完工平台的外露安全边可派生稳定登陆ID（built:实例ID:方向），点击船锚或船上点击板面可航行并自动上岸；上岸沿同一ActorController状态机，仍可由当前登陆点回船。登陆节点/图标为布局投影，不另存一份权威状态；读档重建，当前登陆边受修改保护。 |
| SEA-BUILDING-R14 | 配方集中声明成本、工期、category、role、support、footprint和visual角色，服务通过目录识别地板/摆件，不为每件复制规则；新内容增加目录项与对应表现适配，复用稳定实例、空间和存档协议。未来多层、墙/门、家具、电网等需独立补语义和条款，不把未知配方自动当作培养土。 |
| SEA-BUILDING-R15 | 无固定玩法数量/海域边界，但计算与文件资源有限：布局序列化技术预算4MiB，整档8MiB，提交前包含未来Farm记录的候选容量检查、至少64KiB余量，超出时在扣费前明确提示。临近虚影最多96个、登陆图标局部采样与水线24槽是表现预算，不影响鼠标直接选远处海面。稀疏网格和局部航路不分配从原点到远处的整片海洋；数值需有限且网格在整数表示范围内。不得宣称已验证任意无限实例的帧率或浮点精度。 |

## 操作与空间契约

| 条款 ID | 规则与验收 |
|---|---|
| SEA-BUILDING-R16 | 固定六格、DIY标准/小型培养土及各阶段蔬菜均不阻挡人物，玩家可直接踩踏；导航/胶囊保留脚下木面，不生成种植占地洞口墙。承载、重叠、施工预留和搬移/拆回规则保留；经过不浇水、不收获、不损坏作物，站在种植区可保存恢复。种植配方显式blocks_actor=false，未来实心家具可声明true；固定种植格只有明确元数据声明才参与阻挡。 |

建造手册→选择木板/标准培养土/小型培养土→移动鼠标查看红绿虚影及原因→R旋转、Shift精细→点击接近并开工。岸上远处无可达工地时应先乘船；船上可选独立海面基础。右键回手册，Esc逐级取消选中的搬移/建造模式；退出已付款施工继续。

地图没有人为圈数限制，仍必须遵守真实占地。角色不能隔海遥控施工；独立平台先乘船到旁边建造，完工后从外露边登陆。原六格是新局已拥有的种植区，也是接板起点；固定与DIY种植格在每次布局同步后使用同一套格内/侧边操作点，业务和初始状态归SEA-FARM-R12。新DIY培养土放在新木板并集上，不穿入原有箱体。

没有“拆除回退一格”的隐式业务：每次拆回都保留材料与状态原子性；已种作物不由建造系统收割、退种或清空。已有历史布局不强制通过新布局安全门禁，但新修改不得扩大其不安全程度。

## 实现与扩展入口

- Catalog：配方、几何、承载并集与技术布局字节预算；Service：布局/索引、候选、can_place/begin/tick、can_move/move、can_remove/remove、快照。
- Space：并集外边缘、角色宽度、稀疏连通分量与操作点；Boundary：实际世界占地、泊位、角色、作物拒绝及候选布局检查。
- World：表现、FarmField登记、行走/船阻挡/水线派生；搬移更新原节点，避免注销地格清作物。
- Access：船上工地点、动态登陆点与图标；Controller/Book：精细放置、管理与原因反馈；Main仅装配端口和既有导航/角色流程。
- 扩展资格/世界空间/容量策略通过configure注入，不让规则回读Economy或Main。未来新物件按role选择投影与交互适配，不改既有实例ID含义。
