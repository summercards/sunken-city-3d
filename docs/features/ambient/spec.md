## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-AMBIENT-R01 | 通用植物和区块专属植物分别管理，摆放由场景或明确定义的数据拥有。 |
| SEA-AMBIENT-R02 | 植物效果随所属区块生命周期创建和释放，共享网格与材质避免重复。区块级粒子效果的开关属于数据（`naming.ZONE_PLANT_EFFECTS` 的 `effect`），停用一个区块的粒子不修改 `plant_effect.gd` 的代码路径；停用粒子不得连带关闭同区块的植株摆动（`sway_amplitude` / `wind_strength`）。zone1 自 2026-10-28 起不发粒子。 |
| SEA-AMBIENT-R03 | 生活表现不擅自拥有居民身份、养殖或库存规则。 |
| SEA-AMBIENT-R04 | 植物作为所属建筑的升级附件，通过等级输入控制表现；可移动摆件只发交互意图，许可、移动结果与存档由玩法所有者处理。荷叶为独立装饰，飞鸟、水下鱼群与鲸为场景装饰/动物，不承担捕捞产出。飞鸟轨迹避开太阳房屋顶，并贴屋顶飞行而非悬在画面上沿：烘焙 `baseY` 5.8–9.2 加 `Birds.altitude_offset`（默认 8.5）落在 14.3–17.7 m，对 11.84 m 屋脊保留 ≥1.8 m 净空（下限由 `visual-decorations` 的「屋顶 +1 m」断言守住，往上调须重跑，往下调会先撞断言）。飞鸟的**鼻尖必须指向飞行切线**（资产烘焙自 Three，模型前向为 +Z；`lookAt` / 朝向公式不得按 Godot 默认 -Z 处理，否则整群倒飞）。水面装饰鱼群沉在浪面之下 0.5–1.5 m（按最高点口径，全程不得露出水面）；每群 2–3 种颜色、群内色相拉得开，整群铺开跨度不小于 3 m，单条鱼游程直径不小于 1 m（不是原地抖动）。 |

## 场景组件接口

`scene_component.gd` 提供 `describe()`、`request_interaction(action)` 与 `interaction_requested(instance_id, action)`。可移动摆件允许 inspect/relocate 意图，当前不自动修改 Transform、不扣资源、不写存档。后续摆放玩法必须实现合法位置检查、原子提交和按稳定实例 ID 保存。

植物以 `facility_id`、`attachment_slot` 绑定升级对象；独立花叶通过 `set_upgrade_level(level)` 与可配置 `unlock_level` 显隐，默认阈值 0 保留用户当前美术布局。原有 PlantField 仍接收建筑等级并负责生长。升级价格、消耗和等级真值继续归建筑玩法所有者。

动物使用独立 PackedScene 和 `sample(time)` 动画接口。海面装饰在 World 下随潜水切换隐藏；潜水鱼群复用相同组件并由潜水层注入材质和时钟。动画相位不存档，装饰不注册采集命中面。

鱼体形状、巡游动画与配色取自网页版，两处水体各用一套（`web/underwater-art.js` 的细长型 + 四色轮换用于水下；`web/fish-schools.js` 的扁胖型用于水面）。水面装饰群**沉在浪面之下 0.5–1.5 m**：y 跟随同一套波浪采样，沉深按鱼最高点相对浪面计算，每条鱼独立一档深度形成纵深。不再"抬到浪峰之上"——那会让鱼整条浮在水面上，水面反光直接压在鱼背上。沉深深于 1.5 m 会被水色吃掉、读不出鱼形，是这条范围的上限。单群个体按黄金角铺开、各占一小片地盘，不允许共心排成一圈。

水面装饰群的配色**不沿用网页版的单色薄荷青**：网页版整群同色，俯视机位下读不出个体、也没有活物感。改为每群 2–3 色、三群各取一组（`SURFACE_SETS`），群内按实例色分发并洗牌；水下群仍是网页版那种整群一色按群轮换（自定义 shader 读不到 MultiMesh 实例色，颜色写在 albedo 上）。巡游轨迹在椭圆本轨之外再给个体自己的轨道朝向、低频加减速与小幅侧摆，朝向取路线差分切线。

## 2026-10-30 海鸥只在白天

| 条款 ID | 规则 |
|---|---|
| SEA-AMBIENT-R05 | 海鸥只在 **06:00–18:00** 出现，过了 18:00 整群收起，06:00 之前同样不出现。时段只读 `WorldClock` 的小时：`Main` 把 `world_clock.changed` 转给 `Birds.set_hour(hour)`，鸟群自己不记时间、不存第二份日程，读档/睡觉/跨日都走同一条通道。收起时**同时**关根节点 `visible` 与每只鸟的 `set_process` —— 只改可见性的话十二只鸟整夜还在算 `sample()`；重新出现时从冻结相位接着飞，不瞬移。18:00 是傍晚六点（日落前后），不是清晨六点；这是一条表现规则，不改变日出/日落光照与睡眠日程。 |
