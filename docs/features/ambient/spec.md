## 功能目的与边界

正式或规划入口：区块植被、飞鸟与动态环境。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-AMBIENT-R01 | 通用植物和区块专属植物分别管理，摆放由场景或明确定义的数据拥有。 |
| SEA-AMBIENT-R02 | 植物效果随所属区块生命周期创建和释放，共享网格与材质避免重复。 |
| SEA-AMBIENT-R03 | 生活表现不擅自拥有居民身份、养殖或库存规则。 |

## 所有者、接口与数据

状态/交付所有者：**PlantField / Birds**。正式代码和资源入口：

- [godot/src/ambient](../../../godot/src/ambient)
- [godot/scenes/plants](../../../godot/scenes/plants)

读取上述所有者的公开查询，修改通过其命令或交互入口；事件由拥有该状态的对象发出。具体公开方法、信号和持久化字段见本账本的接口清单。原有稳定 ContentID、场景 ID 和存档键保持不变，重命名须另做迁移。

共享资源的所有权以被依赖功能为准。本功能引用它们，不复制背包数值、资产记录或其他功能规则。规划中的接口尚无实现时必须先补契约再编码。

## 当前实现与待完成边界

美术登记需按源/运行资产分别维护，不把装饰动画计作生活玩法完成。

现有规则继续运行；独立文档、账本和目录归位不代表所有行为已经独立测试，也不代表全部原始目标已实现。阶段事实以本功能账本为准。
