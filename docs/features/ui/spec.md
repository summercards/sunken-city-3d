## 功能目的与边界

正式或规划入口：顶部 HUD、背包、建造、种植与提示。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 所有者、接口与数据

状态/交付所有者：**HUD / UI presenters**。正式代码和资源入口：

- [godot/src/ui](../../../godot/src/ui)

读取上述所有者的公开查询，修改通过其命令或交互入口；事件由拥有该状态的对象发出。具体公开方法、信号和持久化字段见本账本的接口清单。原有稳定 ContentID、场景 ID 和存档键保持不变，重命名须另做迁移。

共享资源的所有权以被依赖功能为准。本功能引用它们，不复制背包数值、资产记录或其他功能规则。规划中的接口尚无实现时必须先补契约再编码。

## 当前实现与待完成边界

HUD 已使用程序化单卡与两页九格，经营详情在同一卡内；具体参数、Cozy token复用/绕过和真实数据链见[单卡交付记录](../../development/2026-10-26_ui_ac_single_card.md)。卡片和状态表现不新增业务写入者。

部分旧经营展示仍直接读取业务字段；功能级面板分别由所属功能代码目录管理。即时出售仅调用现有作物出售命令，鱼/贝壳/珍珠保留码头交易入口；不在UI中创造新经济规则。时钟/潮汐未接入，显示「—」。相机、滤镜、订单、打捞和交互提示保留原所有者，通过 `island_presenters.gd` 装饰现有控件；不复制业务规则。系统暂停与UI偏好由 `island_menu.gd` 管理。

主卡仍遵循任务书九格、状态只读和卡外提示；按用户补充的全界面要求，经营详情增加宽度，独立功能面板居中或靠右。实际覆盖范围见交付记录，不据此声称触控/手柄通过。

现有规则继续运行；独立文档、账本和目录归位不代表所有行为已经独立测试，也不代表全部原始目标已实现。阶段事实以本功能账本为准。
