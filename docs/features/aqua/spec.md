## 功能目的与边界

正式或规划入口：规划：浅水养殖台的养殖交互。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 2026-11-01 家园补给站升级为渔场（第一段）

用户要求：家园补给站那块平台可以升级成渔场，升级入口做在它自己的木牌（广告牌）上，成本木板 100 + 鱼 50，界面与体验跟种植那套一致。本轮只做「升级这件事本身」，养殖生态仍在后面。

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-AQUA-R04 | 家园原补给站木牌气泡仅提供“建造渔场”，先让角色走到牌旁站定，再开建造页；E键进入同一建造页。成本固定木板100+鱼50，背包与保管仓库合并计数、合并扣费。材料不足禁用并说明缺口，已建造不重复扣费。 |
| SEA-AQUA-R05 | 升级成功后旧木牌隐藏，原位置由R10的收获标志与服务菜单接替；原木板台面切换为R06定义的正式渔区外观，临时旗退役。状态仍在可选economy.fishery中，旧档读成未升级；已升级旧档的产鱼兼容见R09/SEA-SAVE-R16。读档同步外观和通行，无需再次交材料。 |

| SEA-AQUA-R07 | 岸前红框水域按明确坐标布置约12×10米围网，包络XZ `[-25.2,-13.2] × [15.8,25.8]`，四角1米切角；网顶约0.96米、底部约−1.24米，均低于1.12米海平面。粗几何菱形网绳、下沉子、圆肚奶油/珊瑚浮漂和四个短旗漂围成封闭渔区，中间直接复用SEA-DECO-ANIMAL-FISH-SCHOOL的现有surface/flat彩色鱼：两群各10条、size_scale=0.5，保留原鱼颜色、深度和游动。两群放在区块的独立FisherySchools节点，与岸坪/围网装配和GLB分离；旧定制鱼组件保留源但退出正式装配。鱼群仅表现，不注册到SeaProps；产出由R09独占结算。浮漂轻随水波。 |
| SEA-AQUA-R08 | 仍由FisheryModel独占unlocked，成本与合并扣料保留；独立FisheryVisual只投影外观、岸坪行走区域、浮漂动画及围网水域占用，收到重复通知不重复生成。升级/恢复/旧档未升级均对称更新；候选存档空间先按候选unlocked校验，再恢复对应地面与角色。岸坪不得生成水中行走面，原登陆点可到收获入口、中部和水边；晾架/工作台/鱼篓不让角色穿过，原泊位船路保留，围网内不让船和随机鱼/木头穿入。 |

## 2026-11-02 鱼群复用与自动产鱼

| 条款 ID | 设计与验收 |
|---|---|
| SEA-AQUA-R09 | 升级后按唯一WorldClock累计产鱼，每4游戏小时产3条鱼，渔场最多积累24条。升级当时不赠鱼；多个周期按经过时间一次结算，睡觉跨时正常计入；满仓时超出部分不积压，收获后同一时刻不立即补满。暂停与现实离线不推进游戏时间；同钟点重复观察、读档不重复发奖。FisheryModel唯一写pending/next_hour，经注入端口向背包原子发放fish；背包空间不足时不减少渔场储量。 |
| SEA-AQUA-R10 | 二阶段隐藏旧木牌，原位置投影独立屏幕圆按钮，直接复用action_bubble：76px青绿圆底、奶油描边、白色action_fish剪影；禁用时灰色，悬停/聚焦暖金与缩放反馈沿用既有偏好。数量在圆下奶油胶囊显示“收获 ×N”，无鱼显示“生长中”。图标和文字均使用CanvasLayer，不使用Sprite3D/Label3D，不能再被海水深度/折射切边。按钮随世界位置投影，点击后按可达性/接近/交互流程直接领取；E键消费同一业务命令。升级/存读对称切换，不把鱼、按钮和渔场设施合成模型。 |

存档v4保持；economy.fishery升为v2，保存unlocked、pending、observed_hour、next_hour。缺失字段的旧功能记录=v1；已升级旧档从恢复时刻起开新周期，不补发历史鱼。v2截断、超过容量、时间越界或过期下一周期均在整档恢复前拒绝，归SEA-SAVE-R16。[交付与证据](../../development/2026-11-02_fishery_production.md)。
