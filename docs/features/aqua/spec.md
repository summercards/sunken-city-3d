## 2026-11-01 家园补给站升级为渔场（第一段）

用户要求：家园补给站那块平台可以升级成渔场，升级入口做在它自己的木牌（广告牌）上，成本木板 100 + 鱼 50，界面与体验跟种植那套一致。本轮只做「升级这件事本身」，养殖生态仍在后面。

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-AQUA-R04 | 家园补给站的木牌气泡里新增「升级为渔场」一项，与商店/仓库/出货箱同一条动线（先让角色走到牌子旁，站定后才开面板）。成本固定为木板 100 + 鱼 50，**背包与保管仓库合并计数、合并扣费**（100 块木板装不进 24 格背包，只认背包等于永远升不了）。材料不足时按钮禁用并在行内写清还差什么；已升级后按钮换成「已完成」，不重复扣费。 |
| SEA-AQUA-R05 | 升级成功后必须立刻有可见变化：木牌文案改为「渔场 · 商店 / 仓库 / 出货箱」，平台上插一面旗作为临时标记（复用建造组件里的旗，明示是临时标记，不冒充正式渔场美术）。状态进存档（`economy.fishery = {version, unlocked}`，不进 required，旧档读成「没升过」）；读档后木牌文案与旗子一并恢复。 |
