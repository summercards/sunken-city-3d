## 功能目的与边界

正式或规划入口：启动 godot/project.godot。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-BOOT-R01 | 正式入口装配海面世界、玩家、船、相机、交互与 HUD；场景负责内容，装配层负责生命周期。 |
| SEA-BOOT-R02 | 船上、岸上和潜水模式由会话状态统一切换，切换后输入与相机不得留在上一模式。 |
| SEA-BOOT-R03 | 调试、自检和截图入口必须可定位，自动测试使用隔离用户数据目录。 |

共享资源的所有权以被依赖功能为准。本功能引用它们，不复制背包数值、资产记录或其他功能规则。规划中的接口尚无实现时必须先补契约再编码。
