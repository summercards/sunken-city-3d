# SEA-ENERGY · 体力与疲劳

[主文档中控](../../../GDD_V1.0.md#sea-energy) · [本功能账本](ledger.md)

设计修订：r1（2026-11-01 新增）。所属系统：生活。参考：《星露谷物语》的体力条与「累到晕倒被抬回家」的节奏，数值按本作的一天行为量重定。

## 功能目的与边界

把「一天做多少事」变成一条可见的预算：每个生产性行为扣一点体力，见底先提醒、再强制休息，第二天上限减半。它不创造产出、不改变任何既有数值，只决定「今天还能做几件」。

本功能拥有体力数值（当前值、上限、惩罚标记）与两条阈值事件；它不拥有种植、建造、采集、打捞的任何规则，也不决定行为该扣多少——那些是行为所有者通过端口来问的。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-ENERGY-R01 | 体力有唯一写入者 `EnergyModel`。新局上限 100，每天正常醒来回满。上限与当前值都进存档；写入之前的老档没有体力记录时按满体力起步，不得读成 0。 |
| SEA-ENERGY-R02 | 每个生产性行为在**真正结算成功那一条路径**上扣体力；被拒绝、被取消、目标消失、背包满都不扣。开销：播种 2、浇水 1、收获 1、建造 4、拆回 3、搬移 3、岸边采集 3、海上打捞 3。行走、购买、存取、睡觉不扣。剩余 1 点时仍允许行动（扣到 0 再触发疲劳流程），不得出现「差 1 点什么都做不了」。 |
| SEA-ENERGY-R03 | 低于上限 25%（且仍大于 0）时给一次疲劳提醒，同一天只提一次；当天回到上限之上后重置，第二天重新可提。提醒只提示，不改变任何行为是否可做。 |
| SEA-ENERGY-R04 | 体力归零立刻进入强制休息：先播一句角色台词「啊，太累了，今天需要休息了。」，再走既有睡觉黑幕过场。台词期间与过场期间吞掉全部输入，重复触发只执行一次；不在读档/恢复中途触发。 |
| SEA-ENERGY-R05 | 被体力逼着睡的那一次，第二天醒来上限减半（50），并把当前值补到该上限。惩罚只挂一天：下一次正常入睡即恢复 100。惩罚标记必须单独存档，不能在读档时被重复叠加（不能读两次变成 25）。 |
| SEA-ENERGY-R06 | 体力条常驻屏幕右下角，位于「锁定视角」圆按钮上方，按同一套缩放系数跟随分辨率，任一玩法状态（含面板打开、航行、潜水）都可见。视觉沿用休闲界面色板：奶油底槽 + 青绿填充；低于 25% 转琥珀，归零转珊瑚。数值文案「体力 当前 / 上限」右对齐压在条上方。 |
| SEA-ENERGY-R07 | 行为所有者与体力的关系只能是**可选端口**：种植规则（`farm.gd`）、建造布局（`building_service.gd`）、采集点（`gather_spot.gd`）在端口未接时照常运行，不得直接访问 `Economy`、`GameState` 或场景节点。体力表只在 `EnergyModel` 里。 |
| SEA-ENERGY-R08 | 一次性建满 12 框架 + 10 摆件这类批量操作允许在夹具里回满体力（那是建造与承载的回归，不是体力经济），但正式玩法里必须真的撞到上限并走强制休息；测试须同时证明「撞得住」与「夹具回满不影响其他断言」。 |

## 所有者、接口与数据

状态所有者：**EnergyModel**（`godot/src/energy/energy_service.gd`，挂在 Economy 下）。

- `spend(action) -> String`：扣费，返回空串表示已扣，否则是拒绝原因。
- `reason(action) -> String`：只问不扣，供交互层在开始动作前拦下。
- `cost_of(action) -> float`、`ratio()`、`is_empty()`。
- `after_sleep(forced)`：醒来结算，唯一改上限的入口。
- `refill()`：立即回满（调试与夹具）。
- 信号 `changed(current, maximum)`、`tired`、`exhausted`。
- 存档：`economy.energy = {version, current, maximum, pending_half}`，不进 required。

消费方：`Economy` 装配端口并转发到 HUD；`Farm`（通过 `farming_ports.spend_energy / energy_reason`）、`BuildingService`（通过 ports 同名两项）、`GatherSpot`（`energy_reason`）、`Main._finish_pick`（打捞）各自在结算点调用。睡觉由 `Main._wake_at_home` 调 `after_sleep(sleep_cycle.forced)`；强制休息由 `Main._on_energy_exhausted` 串起台词与过场。

## 当前实现与待完成边界

已实现 R01–R08 的规则与表现。本轮不做：体力对行走速度/移动距离的影响、食物与药水恢复、体力上限的成长（升级扩容）、NPC 提醒台词轮换。这些都不在本轮需求内，保持未登记状态，不以「已有体力条」冒充。
