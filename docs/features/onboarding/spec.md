# SEA-ONBOARDING · 新旅程码头开场

[主文档中控](../../../GDD_V1.0.md#sea-onboarding) · [独立账本](ledger.md)

设计修订 r1，2026-11-02。新存档玩家站在家园主泊位边，先看海与木码头，再由镜头缓缓靠近，输入名字并完成角色创建。只为新旅程接管镜头和创建步骤，玩法与角色状态仍由各所有者维护。

## 叙事节拍

标题保持原SEA实景与“开始游戏”。无完成档案时，点击后0.45秒文字淡出；角色经ActorController站在真实主泊位，镜头约1.8秒从标题远景推至人物正面三分之四视角，留右侧纸页空间。提示“海风正好，你的故事从这里开始。”随后进入“怎么称呼你？”→“这就是我”搭配→“旅人证”确认。确认成功欢迎玩家，约1秒退回日常跟随镜头，显示玩法HUD、恢复计时与自动保存。已有完成档案继续走原1.1秒入场镜头，不重复取名。

## 条款与验收

| 条款 ID | 规则 |
|---|---|
| SEA-ONBOARDING-R01 | 无完成profile的新旅程点击开始后在真实家园主泊位安全地面站立，人物不在船上，也不生成第二个玩法人物。 |
| SEA-ONBOARDING-R02 | 独立流程状态 idle/arriving/editing/leaving，拒绝重入；镜头从实时标题姿态拉近，完成后平滑回到当前角色跟随机位。 |
| SEA-ONBOARDING-R03 | 全程隐藏玩法HUD、锁世界/镜头输入、暂停世界时间/经营/天气/自动存档，水面与待机表现保留。 |
| SEA-ONBOARDING-R04 | 按姓名→外观→确认推进；支持后退、保留草稿、键盘与鼠标。首创Esc只返回步骤，不能无声跳过创建。 |
| SEA-ONBOARDING-R05 | 首次确认写入角色与码头站位，成功后才解锁玩法；存储失败允许重试，进度不会伪装已保存。未完成退出不保存半成品。 |
| SEA-ONBOARDING-R06 | 已完成档案冷启动直接继续；无profile旧档迁移已完成默认形象；未完成profile继续进入创建，不被自动存档跳过。 |
| SEA-ONBOARDING-R07 | 暂停菜单确认重置走原归档保护，再开始新旅程创建；旧角色档案随旧进度保留在归档中。 |
| SEA-ONBOARDING-R08 | 流程使用注入端口，由装配层处理泊位/控制器/暂停恢复；不得写库存、经济、碰撞、移动规则，不反向依赖Main。 |
| SEA-ONBOARDING-R09 | 结束或取消编辑后释放控件、临时视角和回调，恢复此前各CanvasLayer可见性/处理模式，不残留输入锁。 |
| SEA-ONBOARDING-R10 | 独立行为专项覆盖全链路、旧档继续/重置、输入锁定与失败重试；真实渲染检查拉近/编辑/确认及三分辨率，日志分别记录退出码与未执行项。 |

## 所有权

`godot/src/onboarding/`拥有场景流程与近景构图；`SEA-AVATAR`拥有档案与外观草稿；`SEA-SAVE`拥有原子存储；`SEA-MOVE`拥有上岸；`SEA-CAMERA`拥有日常镜头；Main只注入与协调生命周期。原开始画面的SEA-UI-R21/R22、SEA-CAMERA-R05/R06对完成档案保持；新旅程由本功能接续其入场阶段。
