## 功能目的与边界

正式或规划入口：建造页升级小船，再选择远海。

本功能以这一玩家行为或工程交付闭环为管理粒度，内部操作作为设计条款逐项承接；不按脚本数量拆功能。跨功能前置和关系由主文档本行统一维护。

## 设计条款与验收标准

| 条款 ID | 目标规则 / 应验证的行为 |
|---|---|
| SEA-SHIP-R01 | 升级消耗海贝与材料，满级或不足时不扣资源、不改变等级。 |
| SEA-SHIP-R02 | 二级船开放远海及平台空地播种资格，三级船保留巡航速度提升规则。 |
| SEA-SHIP-R03 | 升级的可见船体变化和更远探索能力属于原设计目标，不能用等级数字代替全部成长表现。 |

## 7. 航海成长与探索设计

### 7.1 航海的角色

航海不是独立于家园之外的小游戏，而是连接家园建设、资源获取和世界扩展的空间纽带。

### 7.2 船只成长方向

| 阶段 | 船只能力 | 解锁内容 |
| --- | --- | --- |
| 木船 | 近距离往返 | 初始屋顶、邻近废墟 |
| 帆船 | 更远距离航行 | 远海沉没街町、新建筑材料 |
| 改良探索船 | 运输、打捞、深水探索 | 深海材料、远距离区域和高阶建筑 |

### 7.3 航线上应出现的内容

- 漂流木料、旧零件和可回收物资。
- 水下建筑、鱼群、巨鲸、废弃车辆和沉没招牌。
- 轻量发现事件，例如一处新屋顶、一艘废弃小船或一段旧时代生活痕迹。
- 不设置强制战斗；风险主要通过路线、天气、深水和船只能力表达。
