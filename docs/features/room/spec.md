# SEA-ROOM · 室内房间（卧室与前厅）

[主文档中控](../../../GDD_V1.0.md#sea-room) · [独立账本](ledger.md)

## 范围

太阳房门口原来的「睡觉」按钮改成「进入房间」；进屋后是一个 5×5 米的方形卧室，
木质地板、白色墙面、后墙一面窗，前侧接一间与外部同语言的白框玻璃前厅。
房间里有一张床，床是可交互类家具、绑睡觉功能，并且将来要能被「布置」功能搬动与旋转。
房间里还有一枚「出门」按钮。

室内是**独立空间**，不叠在太阳房本体里，也不在可航区、屋面或水下任何一个**室外内容**
的邻域里：房间挂在 `World/Interior`，摆在世界 `(0, 200, 0)`。屋外时整个房间隐藏、
碰撞层关闭、退出交互组。

**为什么必须离这么远**（这是 2026-11-06 的实测结论，不是保守取值）：早先把它摆在
太阳房顶上方 `(2.5, 12.6, 1.0)`，房间占 12.6–15.35 米，而海鸥飞行层是 14.3–17.7 米 ——
两者在高度上直接重叠，进屋后有几只海鸥从卧室里穿过去。房间的四壁挡不住海鸥：
它们是独立节点、有自己的 `visible`，且 `birds.set_hour` 会在时段切换时**自己把
visible 设回去**（「在屋里睡到天亮」正好走这条路径）。

所以采用双保险：**挪远**（200 米高度上没有任何室外内容）+ **室内抑制**
（`set_interior_hidden`，让会按时间自显的环境节点被按住）。只做前者，以后加任何
高层/高空内容都会重演；只做后者，房间在视觉上仍贴在屋顶上、换个机位就能看见外面的东西。

房间**不放新场景**：时间、存档、区块注册、相机、UI、行走接口都已经在 main 里跑通，
另开场景等于把这些各做第二份，且存档要分叉。房间作为「一个区块」的形态已经是
正确抽象 —— 它需要的隔离是空间上的，不是场景数量上的。

**屋里就是屋里，窗外什么都没有。** 进屋时海面、船、船迹、所有区块一起收起，
世界背景从「天空盒」切成纯黑（`Environment.BG_COLOR`，黑色），窗玻璃与前厅玻璃
换成室内玻璃实例（固定深灰、不参与色盘 ice 格的天蓝）。所以从窗口或玻璃前厅看出去
是一片黑，不会露出海面或天空 —— 那是「站在屋外看天」的读法，不属于室内。
背景改黑**只动 `background_mode`/`background_color` 两项**，环境光仍取自天空辐照，
房间的白天/傍晚/夜间亮度与外面完全同步。

| SEA-ROOM-R02 | 进出房间使用既有圆幕过场（合拢 0.85 秒 → 全黑 → 1.05 秒打开），**黑幕上不写任何文字**；过场期间输入、行走与存档全部锁住，重复点击只执行一次。 |
| SEA-ROOM-R03 | 房间内部净空 5.0×5.0 米，墙高 2.75 米；木质地板、白色墙面；后墙（-Z）一面 1.5×1.15 米的窗，窗台高 0.95 米；前墙 1.2×2.06 米门洞。 |
| SEA-ROOM-R04 | 前侧接一间白框玻璃前厅：木地板、两侧与正面玻璃、斜面玻璃顶，尺寸 3.44×1.80 米，外檐 2.34 米、靠墙 2.80 米，正面留 1.2 米门洞。 |
| SEA-ROOM-R05 | 镜头始终只缺「朝向镜头的那一侧」：四面墙按相机是否越过**该面墙本身**逐帧决定显隐，相机在房顶以上时天花与前厅顶一起收起；前厅的正面玻璃、门洞立框、立柱、裙墙、圈梁、两侧玻璃各自带朝外法线，走同一套规则。**相机站到前厅前侧（房间局部 z > 2.4）时整座前厅构件全部收起**，只留地板 —— 否则东西两侧玻璃按法线被判成「远侧」而留下，在画面里斜插一块暗板。同一时刻不得出现两面墙同时消失，也不得靠永久删除几何实现。 |
| SEA-ROOM-R06a | 房间整体 `scale=1.5`，跟随角色 `SCALE`（1.5）：几何按 1:1 建模，缩放只在 TSCN 一处。净空 7.5×7.5、门洞 3.09×3.09，净空/身高 = 3.99（原设计按 1.25 m 角色为 4.0）。相机距离与环绕缩放区间按 scale 推导（`uniform_scale()` / `orbit_zoom_range()`），改 scale 时构图自动跟上。 |
| SEA-ROOM-R06 | 室内机位由房间给出**默认值**，但玩家可以自由调整：右键拖动绕房间旋转（任意方位角，四面墙的剖切跟着换面）、滚轮拉近拉远；俯仰夹在 26–72°；距离夹在 8–24 米 × 房间 scale。视点（`target`）钉死在房间上，**左键不平移** —— 房间只有 7.5×7.5 米，允许平移就会拖出房间、四周全黑。离开房间后恢复原机位与跟随，室外相机参数一字不改。 |
| SEA-ROOM-R07 | 室内可走面 = 室内地面 + 1.1 米门槛 + 前厅地板，三块连通；家具（床、床头柜、矮柜）参与角色碰撞，墙体与门框不产生可穿过的缝。 |
| SEA-ROOM-R08 | 床是可交互类家具：`movable=true`，位置与朝向由 SEA-ROOM 的布局状态唯一拥有；绑睡觉，床上睡觉与旧「岸上休息」走同一套命令与黑幕。 |
| SEA-ROOM-R09 | 床的布置入口只接受房间局部坐标：超界先夹回房间内，压到固定陈设或门口时先滑到最近的空位，确实没有空位才拒绝并说明原因。 |
| SEA-ROOM-R10 | 在屋里睡觉，醒来仍在屋里床边；在屋外被到点或体力逼着睡，醒来回到太阳房门口。睡觉地点决定醒来地点。 |
| SEA-ROOM-R11 | 右下角「出门」按钮只在屋里出现；进屋时收起室外的工具栏与视角锁定钮。Esc 暂停菜单与存档不受影响。 |
| SEA-ROOM-R12 | 存档新增独立 `room` 模块（床位置/朝向 + 是否在屋里），**不进 required**：加房间之前的 v4 档按初版床位置补，版本号不变；在屋里存档时世界位置记成太阳房门口，读档后自动回到房间且不重播过场。 |
| SEA-ROOM-R13 | 屋里点地面只走房间地面；点海面、点船、点登陆标记一律不生效 —— 房间没有一片海，不该有航行或靠泊反应。 |
| SEA-ROOM-R14 | 屋里看不到海、看不到天：进屋收起海面/船/船迹与全部区块，世界背景切成纯黑；窗玻璃与前厅玻璃都用室内玻璃实例（`interior_glass=true`，颜色不再取色盘 ice 格）。两种玻璃分开：窗后面是黑的，取深灰（`room_glass.tres`，alpha 0.55）；前厅是能走进去、也会被绕着看的空间，取近透明冷灰（`room_porch_glass.tres`，alpha 0.16）。玻璃后不出现任何可辨识的室外景物。出手（出门、读一份屋外档、回标题）必须完整还原世界显隐与背景。 |

## 所有者与接口

- **`RoomService`**（`godot/src/room/room_service.gd`）：床的摆放与「在不在屋里」的唯一写入者。
  对外 `place_bed(position, yaw) -> {ok, position, yaw, clamped, reason}`、
  `bedside_point()`、`to_dict()`/`from_dict()`、`validate_snapshot()`。不读场景、不读 UI、不读时钟。
- **`RoomScene`**（`room_scene.gd`）：房间区块（`zone_id="room"`）。走的是和海上区块同一套接口
  （`walk_areas` / `area_at` / `pick_walk` / `landing_points`），所以「屋里点地面走路」「交互判定」
  「存档位置校验」都不需要另开通道。提供 `entry_position()` / `inner_position()` / `wake_position()` /
  `camera_pose()` / `apply_layout()` 与 `set_active(on)`。
- **`RoomController`**（`room_controller.gd`）：进出房间的会话流程（过场、世界显隐、机位接管）。
  不碰时间、不碰经济、不写存档。
- **`RoomBed`**（`room_bed.gd`）：床的可交互封装，`sleep_requested` 交给 Main 走既有睡觉命令；
  自带跟随移动的碰撞体。
- **`RoomCutaway`**（`room_cutaway.gd`）：剖切。只读相机位置，不改任何玩法状态。
- **SEA-SLEEP**：拥有睡觉流程、黑幕与时间切换，本次只新增「无文字的圆幕」入口
  （`cover_blank` / `uncover_blank`），原有文字过场与其停留时长一字未改。

跨功能交接：Main 装配命令（入口 → 进屋、床 → 睡觉、出门 → 离屋）；存档收集 `room` 快照；
相机新增 `pose_lock`，只由房间使用，室外行为不变。

## 资产边界

Blender 源：`art_source/rooms/bedroom/v001`（13 个独立组件包，7888 三角面）。
运行 GLB：`godot/assets/models/rooms/bedroom/<key>/<key>.glb`（无内嵌贴图，颜色走公共色盘）。
组件场景：`godot/scenes/components/room/*.tscn`。正式装配：`godot/scenes/rooms/bedroom.tscn`，
由 `main.tscn` 的 `World/Interior` 唯一持有。

灯、机位、行走面与碰撞不进 Blender 输出，归正式 TSCN —— 它们属于玩法与镜头，不属于美术源。
