# 2026-11-24 顶层牧场主楼结构深化

[v011 Blender 源](../../art_source/scenes/ocean_rooftop_farm/v011/ocean_rooftop_farm_v011.blend) · [正式牧场场景](../../godot/scenes/facilities/rooftop_ranch.tscn)

两层均以同一 4.28 米柱网布置 22 个柱位和 22 个窗跨。半米柱采用柱脚、带轻微收分的柱身和承托柱头。每层用独立直梁及角部承托块收口，高台新增侧边梁封边。楼板保留 200 毫米厚度与两层 5.1 米标高差。三个窗下砖层由约 24.5–27.8 厘米厚的实体块组成，砖缝错开，部分砖块凹进。窗框退入开口，梯旁窗台缩短外挑。

44 个窗跨按固定种子错开四种轮廓，破损包括空扇、角片、半片和斜向裂口。缺砖深浅、掉角位置和玻璃组合随窗跨改变，横向相邻跨以及同轴上下层的主变体不同。立面风化同时存在于屋面修复前后。新版总装共 50 种组件和 453 个实例，302 个原铺面、栏杆、码头、梯段及屋顶设施的摆放记录保持一致，正式 Main 的用户摆放和九段屋顶动画沿用。
