# 键盘操控：方向键走人 / 划船 + E 上下船（2026-11-05）

[主文档](../../GDD_V1.0.md#feature-control) · 承接 SEA-MOVE-R20 / SEA-NAV-R15 / SEA-CAMERA-R12 / SEA-INTERACT-R13

## 起因

用户要求把「上下左右」从移动镜头改成正常的角色操控：

> 增加方向键，正常角色操控那种上下左右，键盘鼠标都能组合。现在上下左右是移动镜头的，改成角色移动和船移动。再加一个 E 键可以上船和操作物品，角色到了目标位置就能操作。

旧行为里 `WASD` / 方向键是**平移镜头**，`Q`/`E` 是**旋转镜头**。所以本次是三件事：
方向键改走人、船也走方向键、E 从「转镜头」改回「交互 + 上下船」。

## 键位

| 意图 | 键 | 说明 |
|---|---|---|
| 岸上行走 | `W A S D` 或 `↑ ← ↓ →` | 相对镜头方向；按住连续走，松开即停 |
| 船上划行 | 同上 | 船上待机时按方向键直接开始划；航行中按方向键接管 |
| 上下船 | `E` | 站在泊位旁 2.4 米内上船；船上停稳时上岸 |
| 操作物品 | 按住 `E` | 原有交互不变；靠近目标时提示条显示动作名 |
| 点击走路 / 划船 | 鼠标左键 | 全部保留，与键盘并行 |

镜头只保留鼠标：左键拖拽平移、右键/中键旋转、滚轮与触控板捏合缩放。方向键与 `Q`/`E` 不再碰镜头。

## 实现

### 角色：第 10 个状态 `strolling`

- `ActorController.set_move_intent(dir)` 是键盘移动的唯一写入口；`dir` 是**世界**方向，
  由 `main._camera_relative()` 按镜头朝向折算（前向先投影到水平面）。
- 新增 `src/player/states/strolling.gd` 与 `src/player/actions/free_walk_action.gd`。
  `strolling` 与 `walking` 并列：后者消费一条点击求出的折线，前者每帧消费一个方向。
  两者共用同一个 `CharacterMotor.move_ground`、同一个速度 2.3 m/s、同一个 +Z 朝向契约。
- 只在 `mode()==0`（岸上）生效；船上、潜水、入睡、上下船过场一律清零。
  `main.input_blocked()`（面板、模态、过场、滤镜/相机面板）期间不读键。
- 每一步先判「踩得下去」：
  - 目标点必须投影到当前或邻近的行走面，且高度差 ≤ 0.45 米（选错楼层就拒绝）；
  - 有 `surface_triangles`（斜坡、二层楼板）时交给三角面自己判边界；
  - 矩形行走面再按 2D 净空收边，但**不比当前净空更贴边才放行** ——
    只守 0.30 米阈值会让角色在码头栈桥（实测净空 0.265 米）上原地卡死。
- 分轴尝试（先 x 后 z）：贴着甲板边或门框斜着走时能沿边滑动，不会整个人停住。

### 船：`Boat.set_drive / release_drive / stop_drive`

- 方向 → 期望航向（船头朝 -Z，与 `_forward()` 同一约定），转向复用 `TURN_RATE`、
  加速/减速复用 `ACCEL`/`BRAKE`；保留 30% 最低推进，避免「朝着反方向按一下」时船纹丝不动。
- 位移仍过 `_clear()`（岸线阻挡）：撞岸立刻停、抛 `navigation_blocked`，
  与自动航线共用同一条边界，没有新增「能穿岸」的通路。
- 松手只清方向，速度自己收敛到 0；**速度归零才关 `manual_drive`**，不会一松手就瞬停。
  停稳后 `main` 把 mode 从 2 切回 1（船上待机），避免船明明停了 HUD 还显示在航行。
- 点目标航行时（`sail_to` / `place_at`）主动清掉 `manual_drive`：自动与手动不会同时写位置。

### E 键上下船

- `main._toggle_boat_by_key()` 与点登陆标记复用同一对动作（`_depart` / `_step_ashore`），
  不新增第二条靠岸通道。
- 岸上要求：船正停在这个泊位、角色离站立点 ≤ 2.4 米。
- 与采集并存：附近有交互焦点时按「谁更近」让位 —— 物件比泊位近就归采集。
  一刀切「有焦点就不上船」会让码头上的出货箱永久占住 E（实测就在栈桥上）。
- `InteractPrompt` 新增 `shortcut`：没有交互焦点时也能显示 `E 上船 / E 上岸`。
- 顺带修一处既有缺陷：点击/按 E 上船时角色走到站立点差 6 厘米会被胶囊挡停，
  `walking` 判「前面被挡住了」并取消，整条上船流程前功尽弃。
  现在最后一个航点差 ≤ 0.10 米即算到达（`walk_action.ARRIVE_SLACK`），
  与设计条款「物理支撑的微小安全余量不计为到达失败」一致。

## 边界与未完成

- 手柄、触屏拖拽方向盘未做；键位不可在设置里重绑（沿用代码内注册，同 `interact`）。
- 室内房间（SEA-ROOM）是 `zone_scene` 的子类，`current_zone` 进房时切成 `room`，
  与海上走同一套 `area_at`；结构上可走，但**本轮没有单独实测室内键位行走**，记为 pending。
- 镜头「拖过之后就保持手动构图」的既有语义未改：键盘走路时镜头仍按 `follow` 状态跟随，
  玩家手动接管后不会因为按方向键自动拉回。
- 手动驾驶不做自动靠泊；靠岸仍需点登陆标记或按 E。
