# 2026-11-23 顶层牧场整套替换

正式 [牧场场景](../../godot/scenes/facilities/rooftop_ranch.tscn) 使用 v010 的楼体、铺地、小屋、温室、水塔、风车和陈设。旧楼体、草皮、聚合碰撞及蓝墙红顶工具棚退出正式总装。Main 文件哈希前后一致，区块 ID、泊位 ID 和玩家手摆位姿沿用。码头局部落脚和停船位见[位置台账](../features/world/placed_positions.md)。

开场是破损态。玩家从木码头走两段折返梯上屋顶，前沿和支路通往五处地块、小屋及两个倒塌设施。每处在自己的位置交互。八处完成后，在前沿中段的「牧场设施」处触发约 3.57 秒的分件落装。状态保存在本次场景会话内，重新载入场景会回到破损态。

46 件从另存并重开的 Blender 优化源独立导出，保持 390 个 Godot 场景实例。母版合计从 223,012 三角面清理到 222,768。原 Blend 文件的 SHA-256 与源登记一致。GLB UV 经导出检查，Godot 对每件模型检查四个共享材质角色及暖木色板。楼体和码头提供构件级船壳阻挡，屋面、楼梯、墙和设施使用局部支撑及分段实体。缺失铺面只在复位后加入通行，落装的阻挡在设施归位后启用。
