# 点船上船与靠岸图标换宿主（2026-10-29）

对应条款：[SEA-INTERACT-R07](../features/interact/spec.md)。证据：`board-click`。

## 现象

- 点船没有反应，只有点码头那颗锚形图标才能上船；
- 图标看起来压在船上，说不清它在指船还是指码头；
- 上船之后，图标反而跑到别处，不再提示「靠岸」。

## 根因：一个图标，两个方向，位置却只有一个

`_select_landing()` 用「角色现在在哪」决定这次点击干什么：

| 角色状态 | 点击含义 |
|---|---|
| 在岸上、船停在本泊位 | **上船** |
| 在船上、船在本泊位 | **靠岸** |
| 船不在本泊位 | 叫船过来 |

但图标位置写死在 `dockEdge`（码头边缘），不随含义变化。实测 zone5：

```
boatPark = (16.77, 15.92)   船实际停这
dockEdge = (19.20, 15.40)   图标画这
水平相距  = 2.49 米
```

船身 AABB 半宽约 1.26 米、船长 5.4 米，2.5 米的间距在俯视下几乎重叠 ——
所以「图标在船上」。而船本身没有拾取入口：`boat.gd` 只暴露 `hull_visual()`，
没有碰撞体也没有命中测试，点船体什么都不会发生。

## 修法

### 1. 图标跟着「这次点击会做什么」换宿主

`LandingMarkers` 新增注入式查询，每帧解析一次位置：

```gdscript
var world_query: Callable   # func(zone_id, landing_id, fallback) -> Vector3
```

`main._landing_icon_world()` 的规则：

- 人在岸上 + 船正停在本泊位 → 贴在船上（船上 +1.35 米，不被船体挡住）；
- 其余情况 → 留在 `dockEdge`（点它就是靠岸或叫船）。

判定「船在泊位」复用 `_select_landing` 的同一条件（`not starts_sailing()`
且 `distance < 1.0`），保证图标指向和点击结果永远一致。

### 2. 点船体 = 上船

船没有物理碰撞体（它靠航线与阻挡盒移动，不需要刚体），所以用射线对
**船体本地包围盒**求交 —— 等价于带旋转的 OBB：

```gdscript
func pick_hull(screen: Vector2, camera: Camera3D) -> bool
```

把相机射线变换到 `model` 本地空间，与 `hull_local_aabb()` 做 slab 求交。
比用世界 AABB 精确：船横着停时世界 AABB 会大一圈，点旁边水面也会中。

`main._click_boat()` 只在这些条件下成立：

- 人在岸上（`mode == ASHORE`）；
- 命中船体；
- 船正停在当前泊位（否则提示「船不在泊位，先用登陆点把它叫回来」）。

成立后直接复用 `_select_landing()` 的上船分支，不另写一套上船路径。

### 3. 点击优先级

```
1. 悬浮卡片图标（精确点小图标优先）
2. 海面漂流物
3. 靠岸图标
4. 船体          ← 本轮新增
5. 甲板走路
6. 点水面划船
```

船体排在图标之后：图标只覆盖 30–50 像素，船在屏幕上比它大得多，
点船头船尾都该算「要上这条船」；但精确点图标仍走原路径。

## 验证

`tests/test_board_by_click.gd`，12 项断言：

| # | 断言 |
|---|---|
| 1 | 取到当前泊位 |
| 2 | 显式摆好「岸上 + 船在泊位」前提 |
| 3 | 岸上时图标水平贴合船身（< 0.2 米） |
| 4 | 图标抬到船舱上方（> 1.0 米） |
| 5 | 岸上时图标不再留在码头边缘 |
| 6 | 点船体命中 |
| 7 | 点 14 米外不命中 |
| 8 | 岸上点船被消费为上船流程 |
| 9 | 在船上时图标回到码头边缘 |
| 10 | 在船上点船体不再触发上船 |
| 11 | 船不在泊位时图标留在码头边缘 |
| 12 | （同上，按钮与状态一致性） |

实测：`[board-click] 12 checks, 0 failures`。

真实渲染证据：

- `outputs/board_icon_ashore.png`：图标 = `(16.76, 2.50, 15.92)`，在船中央；
- `outputs/board_icon_aboard.png`：图标 = `(19.20, 2.13, 15.40)`，回到码头边缘。

注意测试**自己立前提**（`reconcile_mode(0)` + `place_at(park)`），
不依赖存档落点 —— 套件里每条检查有独立存档，起手可能已经在船上。

## 未改变的行为

- `_select_landing()` 的三分支逻辑（上船 / 靠岸 / 叫船）未改动；
- 靠近按住 E 的交互（R01/R02）未改动；
- 码头边缘的图标仍可点击，远海未解锁时仍提示升级船只。
