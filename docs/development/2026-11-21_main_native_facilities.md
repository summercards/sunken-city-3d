# 正式 Main 设施实体通行与靠泊

正式玩家胶囊在物理帧读取场景地板、斜坡、墙和平台。删除点击地面移动、交互与施工自动接近、自动航行、自动靠泊、航线预览和地图目的地操作。船的手动行驶、碰岸和转向使用船壳。靠泊时，双方交接都要求实际船壳进入触发区，随后验证停稳、对齐和落脚净空。

固定泊位涵盖阳光房、打捞台与其升级渔场、横滨铁道、浅水养殖台、浮店、顶层牧场、霓虹花园和屋顶街机铺。霓虹花园的登船点移到检修梯脚的实体浮台。其他调整集中在泊位子节点。室内也接入了实体地板和墙体。完工的自建构件携带自身碰撞，动态泊位在平台边缘使用同一船壳触发组件。角色失足落水时回到当前船上。

旧驿站和普通建筑 001、002 从已有模型提取实体船壳阻挡，沿用 Main 手摆的变换与景观用途。正式启动移除旧 `--selftest` 分支，并撤下点击走位、自动驾驶和航线涟漪的废弃探针。居民与建筑系统继续使用各自的地面和水域占用查询。

现有玩法存档格式继续使用。岸上存档以实体支撑与胶囊净空为依据，船位校验凸壳。冷启动等物理场景生效后再验证位置。尚未装配的旧建造快照与渔场阶段仍使用对应候选状态校验。居民寻路和建筑空间查询仍使用独立几何数据。潜水地图和操控沿用原实现。
