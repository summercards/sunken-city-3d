# 2026-11-23 自建物体逐件结构审计

范围为 [SEA-BUILDING](../features/building/spec.md) 正式建造目录。按两套标准核对：模型是否来自五米新版 v002，以及运行时的模型、实体、导航和功能是否采用阳光房式组件归属。固定世界建筑的对照依据是 [SEA-WORLD-R51–R54](../features/world/spec.md)。

Godot 4.7.2 从正式 Main 的 `BuildingService` 读取实际目录，通过 `BuildingWorld.sync()` 逐件投影施工中及完工实例。35 项均加载出网格，手册可用 22 项，兼容隐藏 13 项。32 个 GLB 的实际路径和字节 SHA-256 均与现有资产登记对应。下表网格数为完工实例中的 MeshInstance3D 节点数，包含运行生成的可见网格，不等于制作源部件数量。所有实例都没有本地 WalkArea 或 LandingPoint，运行时生成的通用交互区域与可实际交互的物件分开记录。

## 运行归属

35 项中，30 项完工有角色层实体碰撞，29 项的实体写在预制体自身或子场景里，旧拼接木板的实体由脚本创建。32 个套件件都生成了通用 `InteractionTrigger`，真正注册可交互的套件件只有木储物箱和补水木桶，另有两个种植区各自可交互。拟放置与施工中的实体阻挡取关闭状态。

下层走域由建造布局投影到区块现有 WalkArea。楼梯和上层通行由 `BuildingWorld/AssemblyWalk` 汇总。自建浮台的边缘泊位会生成 DockingArea，本次在新版木平台、两种旧浮台和旧木板上取到了泊位，实际节点位于区块的 WalkArea 下。新版资产与本地碰撞已经使用组件化做法，通行与泊位仍由建造系统集中派生。35 个单件场景均未加载建筑落装 AnimationPlayer。
