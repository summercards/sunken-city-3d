## 地形设计和拼接

场地仍240×240米、100个24米域，中央不缺地板。以主街/院落横向高程剖面组织两侧平台和一处宽下沉街坊：

```text
世界X： -120 —— -72  \  -48 ——————— +24  /  +48 —— +120
高差H：   0       0   \ -4.8      -4.8 /    0       0
```

- 高差4.8米；坡长24米；坡度 `atan(4.8/24)=11.3099°`。这是真实几何缓坡，不是随机升降、接缝错层或细碎顶点噪声。
- 上平台一般铺地顶约Z=-61.3，下沉平台约-66.1；海面沿用Z=1.12。运河床更低，最低几何Z=-68.1；全部保持水面以下。
- 坡道是真实带厚度楔体，边缘精确连接相邻域；车行缓坡保留沥青色块与标线，不把马路在坡口换成没有道路的广场。
- 运河坡岸共用一份沿局部轴变形的组件，实例旋转/标高配套；运河槽末端保留设计性的岸壁高差，不把槽底台阶当作普通人行接缝。
- 独立验收从真实三角形做BVH射线，对180共边逐点采样；普通边只允许原路沿0.225米范围的设计台阶，运河沟槽中带单独声明。修正了初轮广场裸边0.3米误差和运河坡岸0.1米误差，没有通过提高门槛把缺陷判绿。
- 建筑保持刚性，按实际基底顶点采样地形偏移，有斜坡的一侧可表现为部分埋入沉积地面；不允许整栋悬浮。不会对已经保存的阳光房/牧场等正式游戏设施做任何修改。
