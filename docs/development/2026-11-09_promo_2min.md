# 2026-11-09 2 分钟宣传片：实机逐帧录制 + 现做配乐

[主文档](../../GDD_V1.0.md#feature-control) · [分镜与取舍](../../promo/分镜脚本_v3_实机2分钟.md)

用户要求：录制并制作一支 2 分钟左右的游戏宣传片，基于游戏的各种情景、功能与特色，
**注重内容与玩法演示**，自己录制剪辑，时间分配自行决定。本文记录做法与实测，不改任何玩法条款。

## 产物

| 文件 | 参数 |
|---|---|
| `promo/renders/sea_promo_120s_1080p.mp4` | 1920×1080 · 30fps · **120.000s** · H.264 CRF19 + AAC 192k · 115MB |
| `promo/renders/sea_promo_120s_1080p_share.mp4` | 同上，CRF25，43MB |

母版帧数 3601（3600 帧时间轴 + 1 帧收尾），音频峰值 −1.0 dB、均值 −14.6 dB。

## 没有用外部录屏，也没有用生成画面

`promo/` 里原有的 v1 / v2 分镜是给 ComfyUI 的 t2v 提示词，跟当前版本的画面不是一回事。
这支片子全部走游戏自己的渲染：

```
python scripts/build_promo_project.py --run-dir <工程外目录> --width 1920 --height 1080
godot --path <run>/project --resolution 1920x1080 --fixed-fps 30 \
      --write-movie out.avi --script res://tools/record_promo_2min.gd
```

`--fixed-fps 30` 把时间轴和渲染解耦，机器再慢也不掉帧，3600 帧严格等于 120.000 秒。
实测录制约为实时的 40%（1080p 全片约 5 分钟），GPU 每帧 9ms 左右，编码 14ms。

`scripts/build_promo_project.py` 复用 `scripts/run_verification.py` 的隔离口径：
`custom_user_dir_name` 在 Autoload 构造之前改写，`assets`/`terrain`/`.godot/imported`
用目录联接只读挂载，仓库 `project.godot` 不动，只把 viewport 从 1600×1000 换成 1920×1080。
录完的用户数据目录按 `sea-promo/<run>` 留在 AppData，不递归删除。

`godot/tools/record_promo_2min.gd` 是真实驱动：点击开始按钮走 `_enter_game`，
走向菜箱走 `_approach` → `actor_controller`，播种/浇水/收获走 `FarmPlot.perform`，
上船出航走 `_select_landing`，下潜走 `_on_dive`，上浮走 `dive.surface()`。
没有瞬移角色，也没有伪造奖励事件。

## 三处只为这段素材做的会话内调整

写在录制脚本里，不进正式代码：

- **船速 ×2**：`boat.speed_multiplier` 回调注入，只影响本进程。原速 2.6 m/s，
  家园到浅水平台一个来回要十几秒，占掉整条片子五分之一。
- **界面收敛**：「视野 x%」浮标（逐帧调机位会刷成常驻）与底部操作大卡片（站定即可互动物时整段常驻）逐帧隐藏。
  用的是 `RenderingServer.frame_pre_draw`，必须在节点 `_process` 之后、渲染之前改。
- **相机锁**：每帧重申一次目标/距离/方位。只设一次会被跟随逻辑、模态面板、
  过场 tween 各自抢回去——第一版就是这样丢了三段镜头。

另外两处用的是既有预览命令，不算新口子：`farm.debug_set_growth` 推生长（16 步）、
`building.tick` 推施工（30 帧，能看到 ghost 转实体）。

## 结构

三幕十三镜，详见 [分镜脚本](../../promo/分镜脚本_v3_实机2分钟.md)。

- **家**（0–38s）：标题 → 俯瞰收到甲板 → 走向菜箱 → 播种 → 浇水与生长延时 → 收获
- **造**（38–55s）：建造手册 → 海上扩建，四块木板逐块成形
- **走**（55–120s）：出航 → 海上补给站 → 横滨铁道 → 回港下潜 → 沉没旧城 → 入夜 → 收尾

节奏按「静 → 动 → 静」。前 40 秒低机位慢推，中段建造与航行提速（切换变快 + 船速 ×2），
末段放慢到夜景，用亮度落差收束。收获段保留角色俯身、举高、入包的完整 2.4 秒。

## 字幕与配乐

字幕不生成、不外部校对，直接 `drawtext` + 分段 alpha 斜坡烧进画面，字体用工程内的
`NotoSansSC-Regular.otf`，奶油白配海色投影，13 句。「建造手册」那句会压到面板，单独上移到顶部。

工程里没有音频资产（`assets/` 下无 wav/ogg/mp3），所以配乐是现做的合成音轨：
粉噪低通成海、C–Am–F–G 长起音和弦垫、三层五声音阶拨弦琶音，26 秒进入 / 76 秒加高八度 /
112 秒收掉，按段落给 0.55–1.0 的增益。没有外部素材，无授权风险。

## 已知取舍

- **水下偏暗**：家园海底的旧城在 56 米深度，原始画面接近黑。成片对 87.4–97.8 秒做了
  `brightness=0.045 / gamma=1.14` 的轻度提亮；试过 0.10/1.30，会发灰起雾，放弃。
- **水下没有鱼群**：家园海底的生态集中在阳光房周围，旧城街区那段是空的。这一段靠立面和天光。
- **下潜 1.5 秒纯黑**是游戏本身的圆幕过场（0.85s 合拢 / 1.05s 打开），没有剪，因为玩家真实会看到。
- **送礼亭 / 霓虹花园 / 顶层牧场没进片**：前者封闭主体，后两处机位拍到的是空白海面或只见墙面。
- **UI 全部保留**：这是玩法演示片，HUD、面板、气泡都是内容。
