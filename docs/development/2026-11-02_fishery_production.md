# 渔场彩色鱼群、收获入口与自动产鱼（2026-11-02）

本次按用户最新参考修订：鱼群直接用既有海面彩色小鱼，与渔场设施模型分离；二阶段不保留旧木牌，原位置显示收获入口；渔场自动增加可领取鱼资源。用户已授权设计、接入与验收。

## 最终行为

- 设施正式装配为11类64个组件实例；移除14个旧定制鱼实例。现有SEA-DECO-ANIMAL-FISH-SCHOOL以zone1/FisherySchools独立复用两群各10条，surface/flat、size_scale=0.5，与截图同一鱼几何、颜色、深度和游动。鱼群只表现，不注册为随机拾取物。
- 未升级保留旧木牌；升级后隐藏旧木牌，原位置显示独立鱼图标。没有鱼时显示“生长中”，有鱼显示“收获 ×N”。点击图标打开操作气泡，按现有可达性、走近和交互流程收获；E键转发同一业务命令。商店、仓库、出货箱在此入口继续使用。
- 每4游戏小时积累3条鱼，最多24条；升级不赠鱼。睡觉跨时按唯一WorldClock结算完整周期；满仓溢出不积压，收走后同钟点不会补满。点击收获把全部鱼原子放入背包并显示入包反馈；空间不足不扣渔场储量。现实离线不推进游戏时间。

归SEA-AQUA-R05/R07/R09/R10、SEA-ASSET-R39、SEA-SAVE-R16。投苗、投喂、第五区特殊产物仍为规划。

## 状态与存档

FisheryModel唯一写入unlocked、pending和产鱼时刻；时间从WorldClock.observe注入，背包检查和原子入包从Economy组合时注入。模型不访问全局Economy/Main；FisheryVisual只负责设施、岸坪和水域投影，FisheryHarvest只显示并转发操作。

根存档v4保持，economy.fishery功能记录升为v2：version、unlocked、pending、observed_hour、next_hour。v1已升级档从恢复时刻开新周期，储量为0，不补发历史鱼；无功能记录仍为未升级。v2截断、超容量、下一周期不合法、观察时间超前均在整档恢复前拒绝。重复观察当前钟点和反复读档不增加鱼，已收获同一储量不能再次领取。v1伪带新字段也不会注入未验证储量。

修正同日功能条款撞号：原渔场空间存档条款改为SEA-SAVE-R15，保留另一任务的重置存档SEA-SAVE-R14；没有覆盖重置存档设计。
