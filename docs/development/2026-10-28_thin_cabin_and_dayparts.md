# 太阳能木屋薄板与分时光照

对应SEA-ASSET-R26、SEA-OCEAN-R12；同时保持SEA-ASSET-R25的基座出檐与水位接合契约。

## 模型与颜色

以保存的v007派生[v008](../../art_source/scenes/sunny_bloom_retreat/v008/README.md)，旧源与旧色板哈希保护。参考图片中的家园补给站来自独立salvage_station组件：对实际GLB连通几何量测，木板厚0.18米。小屋各层铺板改为约0.22米，主平台原厚0.69米，减薄约68%；后侧缩放较小的延伸板约0.18米。

木色采用参考网格顶面的暖棕色#C49C6E，配轻微浅深变化#CAA576/#BB9265。全部地坪、前平台和栈桥改用这组色；不再保留橙红/赭黄横板。公共色板另存[sea_cabin_timber_8x8_512.png](../../art_source/shared/palettes/sea_cabin_timber_8x8_512.png)，旧版图保留。

源中木板顶面固定后收薄，调整支撑墙/下层立柱以封闭露台底间隙；其余摆位和木板错落保留。独立优化文件先保存重开，再导出逐件GLB；不导出整屋GLB、不运行旧全区生成器。

## 运行接合

海上根Y从-0.30改为-0.77；主铺板顶面由1.85降至1.38，底面仍为1.16，水面1.12，上方留0.04米。海下基座的缩放/出檐/位移保留，与薄木板底面接合。

同步当前正式场景的上岸点、行走面、旧菜箱、出货箱、睡觉入口高度，保持行走矩形；船泊位世界Y保持1.12。zones.json的相应查询基准同步，避免仍返回旧2.15米。正式区块手改与设施独立包装保留。

## 光照时段

| 时段 | 光照 |
|---|---|
| 07:00—11:00 | 完整恢复原09:00太阳、补光、天空、水色与朝向 |
| 11:00—12:00 | 平滑过渡至正午 |
| 12:00—14:00 | 较亮、较高太阳和更短阴影的正午 |
| 14:00—14:12 | 边界短过渡 |
| 14:12—16:00 | 较低、更暖、影子转向的下午 |
| 16:00—17:00 | 转入夕阳 |
| 17:00—19:00 | 低角度橙红太阳与暖色环境，18:18后逐渐熄灭 |
| 19:00—次日05:30 | 太阳、三盏补光、环境光、天空和水面日光提亮为零 |
| 05:30—07:00 | 黎明和06点醒来，逐步回到上午基准 |

DaylightRig仍是唯一光照写入者。此前三盏固定补光和水面/水下自发光会在关太阳后保持亮度，本轮全部跟随该装置。world_daylight只控制日光来源的材质提亮，UI与有意的自发光标记保留；没有添加屏幕黑幕。夜间将环境对比度从原低对比恢复到1，避免RGB零被抬成灰；07–11点完整恢复原参数。未修改日历推进、07点经营结算或23点睡觉规则。
