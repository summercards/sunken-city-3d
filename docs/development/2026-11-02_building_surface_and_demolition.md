# 2026-11-02 梯顶续建、通用平台平面与锤子拆除

归属 SEA-BUILDING-R27/R28/R29，修订 R01/R04/R05/R06/R11/R12/R19/R20/R22/R23/R26；关联SEA-UI和SEA-MOVE仅为输入与派生空间适配。用户本轮明确要求覆盖旧“只有基础层能放结构”“二层先凑四角柱”的限制。

## 本轮行为

- 楼梯建好后，普通拼接木板、4×4浮台、2×4浮台和原二层木楼板都可直接接在梯顶，再沿同一平面续建。指向梯顶自动选择其高度，不必先知道U键或补四角柱。
- 同一种平台在基础层或上层都提供承载、行走、种植与家具功能；区别保存在`py`。墙、窗、门框、柱、栏杆及新楼梯可放在上层，不再把它们强制压回基础层。下一段楼梯按其实际底部高度派生高端，纯规则覆盖5.6米平面。
- 普通构件按0.1米自由摆位，Shift细调到0.01米，结构不再强制1米网格。G开关辅助吸附，U循环已有平台/梯顶平面，H恢复自动识别。旧网格板和旧自由坐标不被迁移或重排。
- 搬移继承原楼层，显示目的地模型虚影及合法颜色；放置阶段允许滚轮缩放、中键旋转和已有键盘镜头输入，书本和拆除确认仍锁世界输入。
- 右上新增独立锤子按钮；按下后显示锤子指针，悬停已建物件出现轮廓。点击合法对象弹“是·拆除 / 否·保留”，列出材料返还，默认焦点否。否或Esc保留物件，是才接近并重验后拆回；不会在打开确认时退款。

承载、实际占位、施工材料/体力、作物所有权和安全通路保护保留；未增加第二份Farm或库存。用户没有要求桌椅动作、电网或风铃声音，本轮未扩充这些功能。

## 对上轮6项审计缺陷的处理

| 上轮编号 | 修复 |
|---|---|
| BUILD-AUDIT-01 混合摆件搬移后存档拒绝 | 新旧摆件改用同一高度与间距规则；快照同时读取全部记录后逐项校验，不受创建/保存顺序影响。默认0.1米搬灯产生的1.3厘米间隙在修改前拒绝，原布局保持可保存；旧档几何兼容不靠重新舍入 |
| BUILD-AUDIT-02 二层家具导致导航接缝断开 | 所有家具切口坐标先按统一精度归一，再同步到相邻平面的三角分区；精确导航复用顶点，过滤退化三角。物理地面和已留身体余量的导航平面分开投影，避免再次内收 |
| BUILD-AUDIT-03 拆桥切断二层返程 | 候选布局检查同源的平面/坡面连通图；保护角色落脚点、原有平台联系和通往楼梯的路径。正常拆无依附摆件仍可退款，不能拆中间桥或唯一返程梯来困住角色 |
| BUILD-AUDIT-04 搬移无虚影 | 新建和搬移都按目标物件生成焦点虚影；原物保留到提交，取消不动布局 |
| BUILD-AUDIT-05 二层培养土落在楼下 | 培养土与套件统一保存py、查同高平台并集；正式Farm地格投影随实例高度恢复，二层播种、带作物搬移和读盘验证 |
| BUILD-AUDIT-06 门洞管理误选 | 管理点选检测实际可见网格三角，不把门洞当实心AABB；点选本身也不再依赖水平建造平面的射线交点，低视角仍能选门后家具 |

同高木板才参与基础层水线、船阻挡和动态登陆；上层平台不会在水面生成新泊位或泡沫。屋顶仍不提供行走面。

## 验证方法与过程

所有运行由 `scripts/run_verification.py` 创建工程外项目和独立用户目录，不使用玩家槽位。新增：

- `building-surfaces`：正式Service/World/Controller与Main、实际鼠标、真实胶囊、NavigationServer、Farm、磁盘JSON存读。覆盖梯顶四配方、自动选层、实际接近开工、爬楼、二层家具接缝、拆桥/拆梯保护、上层种植搬移、自由坐标、搬移虚影、镜头输入、锤子确认/取消/退款与门洞点选。
- `visual-building-surfaces`：相同流程用真实渲染器，输出二层场景、搬移虚影、锤子悬停及确认窗。
- `building-demolition`：独立控件交互，默认否、重复确认防护、Esc层级、目标副本、退款显示、跨分辨率布局和鼠标恢复。

既有专项按本轮设计更新：kit-safety不再要求四角柱齐；building-kit的结构预览改验0.1米自由坐标；旧DIY/兼容拆除输入补明确点击“是”，未直接跳过确认；海上独立起点夹具补与真实控制器一致的`origin=boat`。保留重复扣费、满包退款、依附和坏档等原门禁。

原性能测试标45块但实际只建成21块。本轮夹具离开固定平台占地，并逐块确认创建成功、逐档确认数量，实测9/25/45/100块；纯吸附耗时见机器记录，不外推为完整GPU帧率。

过程失败按原始日志保留：首次规则类型推导错误已修；原格网无关字段和极端坐标保护在统一规则时出现回归，已恢复并通过open-rules；早期梯顶站位采样太稀无法接近，现显式采楼梯高端；导航精度重复切点导致接缝失败，已统一坐标并过滤退化面；上层培养土误走基础层操作点分支已修。旧四角柱/整米预览/直接拆除断言按用户新要求改为正向新行为，未作为产品失败掩盖。门洞低视角最后一次补测发现选取前被水平平面早退，已修复，最终结果另列。
