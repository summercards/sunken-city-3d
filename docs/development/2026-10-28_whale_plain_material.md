# 巨鲸材质退回普通材质 + 下沉更深

- 日期：2026-10-28
- 功能：SEA-AMBIENT（场景装饰·动物）
- 资产：`SEA-DECO-ANIMAL-WHALE` v003 → v004
- 依据：按图反馈 ——"改成普通材质，深灰色即可，不要自发光这些额外效果，会接收光照也会接收其它信息"；随后追加"把这条鲸鱼的下沉做得更深一点"

## 改了什么

### 1. 材质：toon 演出 → 普通标准材质

| 项 | 改前 (v003) | 改后 (v004) |
|---|---|---|
| 材质类型 | `ShaderMaterial` + `toon.gdshader` | `StandardMaterial3D` |
| 颜色 | 皮肤 `#062356`、鳍 `#16589e`（网页版深蓝） | 皮肤 `#59606a`、鳍 `#4c525b`（深灰，鳍暗半档） |
| 水下深度染色 | 开，`depth_tint_strength = 2.0` | **摘除** |
| 环境光补偿 | `ambient_boost = 0.55` | **摘除** |
| 水下辉光 | `uw_glow_amount = 0.60` | **摘除** |
| 描边 | 背面 + 顶点外扩 0.10 m 青色壳，7 个构件各多渲一遍 | **摘除**（不再有 `Rim` 节点） |
| 粗糙度 / 金属度 | — | `0.88` / `0.0` |
| 光照响应 | 自定义 `light()` 半兰伯特分档 | 引擎默认，走场景光照、阴影、后处理 |

鲸此后与场景里其它物体走同一条渲染链路，不再单独做补偿。

### 关键约束（易踩）

**海面世界与水下世界是两张独立地图**，潜水时 `world_root` 整个隐藏（`decorations follow dive lifecycle` 断言就在守这条）。鲸挂在 `scenes/world/environment.tscn` 的 `Animals` 下，属于海面世界，因此：

- 它只能被水面俯视看到；
- 沉过 `-15` 就等于从游戏里消失，不是"藏起来了"。

原先按字面执行"再挪 10–20 m"取 `-18.6`，实测完全不可见，已按主人指定改为锚定倒数第三层 `-11.86`。

## 连带修复

`godot/src/bootstrap/main.gd:1613` 的 `var docked := ...` 改成显式 `var docked: bool = ...`。

原因：`boat` 声明为 `Node3D`，`starts_sailing()` 不在基类上，一旦场景重导入让 Godot 重解析该脚本，整条表达式退化为 Variant，类型推断直接报解析错误 —— 而 `main.gd` 解析失败会让整个游戏加载不了。改动鲸的场景文件后重导入时踩到，属于潜伏问题被提前引爆，不是本次材质改动引起。

## 验证

| 检查 | 结果 |
|---|---|
| `decorations`（headless） | PASS，exit=0 |
| `visual-fish-schools`（真实渲染，`whale_storey3`） | PASS，exit=0 |

`visual-fish-schools` 的材质断言整段反转，现在是"盯住这些效果不许回来"：

- 材质必须是 `StandardMaterial3D`
- 不许 `emission_enabled`
- 不许 `SHADING_MODE_UNSHADED`（必须接光照）
- 不许存在 `Rim` 描边节点
- 色相接近中性（RGB 极差 < 0.10）
- 亮度落在深灰区间（0.28–0.48）
- `roughness ≥ 0.7`、`metallic == 0`
- `y` 必须等于 `-11.86`（等值断言：基座层高改动会立刻红）
- 深度落在 12–14 m
- `dive_sway ≥ 1.0`
- 起伏最高点背脊仍在水下（余量 > 1.0 m）

实拍证据：`fish-schools-whale-top.png`、`fish-schools-whale-quarter.png`（俯视与四分之三机位）。`-11.86` 档下鲸身读作一团比周围略深的水色，可见轮廓与尾鳍，细节被吸收抹平 —— 即"隐约剪影"。

## 明确接受的代价

普通材质在水下 4–6 m 会被水体吸收明显压暗 —— 这是"不加自发光、不做深度染色补偿"后的必然结果。要更亮就调场景光照，不在材质里作弊。
