# B1109A 低面数优化版

## 目标

基于未覆盖的 `v003` 候选另存一份低面数衍生源，目标是整栋 92 个可见组件实例展开后约 10,000 个三角面。v001、v002、v003 均保留，未修改 Godot，未替换已登记主源。

## 本轮按主人要求处理

- 删除一楼檐牌、瓶罐、墙面告示、菜单、侧面广告中的 3D 字体。
- 保留上方主招牌 `廖孖記`，用于建筑远景识别。
- 一楼优先减面：去掉平台砖缝、筐格条、部分窗栅、衣物花纹与衣扣、天线抱箍、部分管卡和梯档。
- 空调外机改为方形大体量与矩形百叶，移除风机圆环、圆网、扇叶等高成本圆形细节；外机识别仍由方形机壳和矩形百叶保留。
- 风扇护罩、天线等细碎圆件降低边数或删除；上层屋顶、小屋、主招牌、遮阳篷、平台和植物主轮廓保留。
- 倒角与圆角不再追求高精段数，使用低比例 Decimate 保留轮廓，不做全场景破坏性布尔。
