# 2026-11-14 场景工坊红框布局纠偏

## 原因和目标

用户示意红框指向模型预览上方空白横栏。上轮却增加了全宽身份、模块、模组三层面板，加上生成栏、工具栏、底部说明，实际占用过多编辑面积。822/0验证只检查节点存在和配方合法，不能证明布局符合示意。此次不沿用该视觉结论。

## 实际改动

- `godot/addons/building_workshop/editor_screen.gd`
  - 常驻主界面仅一行主操作、一行文档摘要、工作区和单行高亮状态。
  - 模块导航放在预览列上方，单行、左右箭头、横向滚动和自动跟随选中项，不再HFlow换行。
  - 身份输入和四个已有默认模组经顶部按钮打开弹窗，不再占常驻高度；身份和模组功能保留。
  - 次要操作（新建、另存、在3D打开、复制样例）及保存路径/材质/bundle说明迁入文件页。
  - 删除工作区外层滚动，左参数/右槽位分别滚动；右槽位默认关闭，分隔可拖，窄屏最多开一侧，缩窗也生效；可一键专注预览。
  - 不缩小主字体，按钮18px、标签至少16px；只压缩无用边距与常驻内容。
  - 状态保持单行，高亮、tooltip、详情可选择文本、复制完整内容；长错误不撑高界面。
  - 去除模块按钮重复pressed回调和取消确认重复回调。
- `godot/addons/building_workshop/upgrade_verification.gd`
  - 增加布局真实矩形/父链/可用面积门禁，不再只检查存在。
  - 测三档定尺寸主屏、侧栏切换/缩窗、单连接、末端导航、长提示复制详情、模组弹窗取消保护。
  - 同一真实EditorPlugin主屏临时置于定尺寸SubViewport渲染，再恢复编辑器父级，避免Mac窗口管理器分辨率不一致。
  - 复制断言前保存剪贴板，结束恢复。
