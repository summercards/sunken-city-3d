# 正式海面设施统一装配

沿用阳光房当前装配方式，在正式项目接入实体碰撞、泊位和交互区域。主场景摆位取用户保存的变换，子组件位置见[摆放台账](../features/world/placed_positions.md)。潜水沿用独立场景。

| 设施 | 本次落地 |
|---|---|
| 阳光房与卧室 | 以场景甲板、桥、上下楼端点和门口热区为基准。复验正式启动、海上往返、进出房间与睡醒。 |
| 打捞台与渔场 | 打捞台拥有共用泊位、绞盘、升级牌和绳索。渔场实例内有岸坪、围网船壳碰撞、独立收获点、鱼群与水域标记。升级和读档同步切换实体与导航轮廓。 |
| 横滨铁道 | 各站台持有自己的实体网格。西站台带泊位和零件，东站台带玻璃。跳板持有自己的板面、护栏碰撞和导航面。 |
| 浅水养殖台 | 主平台持有碰撞、泊位、培养木甲板及菜箱、种子和鱼。自建甲板和泊位使用建造系统的组件数据。 |
| 霓虹花园 | 左、后、右三座屋顶、菜园桥和检修浮台各用局部网格。检修浮台自带泊位与梯端，折返梯随左楼，豆豆的五个站位随菜园桥。 |
| 浮店、顶层牧场、屋顶街机铺 | 复用各自已有的场景实体和泊位。街机铺的西甲板为开放区域。 |
| 旧驿站、普通建筑 001 和 002 | 景观船壳阻挡随建筑，三处均经凸壳扫掠验证。 |
| 工坊海风公寓 | Main 中保留手摆候选身份和候选碰撞层。 |

正式区块撤下旧模型切换和三份被替换的聚合碰撞。采集物、绞盘和升级牌的位置改由场景保存，移除相应的运行时位置生成入口。历史摆放表仍供离线工具追溯和读取。引擎导航网格服务于 NPC 等查询，建造、漂流物和岸线保留各自的空间数据。
