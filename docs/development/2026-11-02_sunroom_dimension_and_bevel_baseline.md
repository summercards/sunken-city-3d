# 2026-11-02 · 阳光房尺寸与倒角基准拉取

所属功能：SEA-ASSET（R06 倒角、R07 尺度、R25 基座关系）。本次只做**测量与归档**，
不新建几何、不改源、不改账本条数。

## 目的

回答"柱子、地板、楼高、门宽各是多少，倒角多少"这个问题时，此前只能翻 `building_scale.json`
的运行时摘要，倒角完全无据可查（只有 skill 里一句"0.01–0.08 米"）。本次把两类数据一次量清：

1. 主体尺寸从源 → basis → 运行时的完整链路；
2. 倒角的段数与宽度档位。

## 方法

新增只读探针 `tools/blender/sunny_bloom_retreat/probe_bevel_metrics.py`，对
`art_source/scenes/sunny_bloom_retreat/v008/sunny_bloom_retreat.blend` 执行三步，不保存文件：

1. 逐 mesh 记录源尺寸、三角面、面宽中位数。
2. 倒角反推：v008 源含 **0 个 BEVEL 修改器**（倒角已在导出前求值），故对每个 `188 三角`
   的单体重建同尺寸立方体，先按三角数匹配段数（1/2/3/4 段中只有 3 段命中 188），
   再用"面宽 ∝ 倒角宽"的线性关系解出宽度。
3. 洞口检查：统计开放边界边，判定墙体是否真的开洞。

## 结果

**尺寸**（运行时米制，详见新文档）：

- 底层净高 4.866335，层高 5.086335（+0.220000 楼板）
- 主柱 0.517500 见方 × 4.866335 高；上层装饰柱 0.388125 × 3.094650
- 楼板 / 露台板 / 主铺板厚 0.220000；主平台板宽 0.893551，节距 0.92，净缝 0.026449
- 门体块 1.8285 宽 × 3.0708 高 × 0.4744 厚
- basis 只有四种组合（均匀 1.725 / 竖向 1.587 / 主柱竖向 1.707486 / 装饰柱 1.29375+1.085842），
  没有统一倍率

**倒角**：33 个可反推单体全部 `segments = 3`，宽度收敛为 11 个档位
0.025 / 0.02567 / 0.02631 / 0.032 / 0.045 / 0.05456 / 0.055 / 0.070 / 0.080 / 0.095 米（源单位）。
主档 0.055 与生成器 `tools/blender/sunny_bloom_retreat/build.py:131` 的 `bevel=.055` 一致。
主平台板倒角为板厚的 42.8%，是全套最紧的一档。

**门窗**：`house_mesh` / `entry_mesh` / `door_mesh` 与三档窗的开放边界边数均为 0，
墙是封闭实体、门窗是贴面体块，**不存在净洞口**。此前 caveat 只说"不是已量出的净门洞"，
现在有几何证据。
