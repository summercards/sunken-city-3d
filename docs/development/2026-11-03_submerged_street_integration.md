# 2026-11-03 沉没街景十栋：Godot 接入 + 第二轮返工

承接 `2026-11-02_submerged_street.md`。本轮做两件事：把十栋接进 `main.tscn`，再按接入后的真实观感返工。**返工发现的缺陷比接入本身多**，所以下面按"发现—原因—处理"记，而不是按时间顺序。

## 一、接入

- `tools/godot/submerged_street_import.py`：读 `catalog.json` + `component_plan.json` → 生成 10 个材质 `.tres`（按 GLB 里 glTF material 名对应角色，不靠顺序假设）→ 生成 10 个 `PackedScene` → 在 `main.tscn` 的 `World` 下插一组 `UnderwaterStreet`。
- 位置约束四条，全部量过：不压 Zone2 横滨站（x −40.4..−19.6, z −27.5..−8.5）、不压 Zone1 家园、不压现有六栋水下景观（x ≥ −21.5）、落在相机 `pan_bounds`（±77）内。47 米宽的街区塞不进"西侧剩余 32 米"，所以主位移给到 Z（+45），X 只 −9。
- **高度按屋顶对齐水面**，不是按底板齐平。现有六栋水下景观就是这样摆的（顶面 −1.1..−3.7）。底板齐平会让 3.6–16.5 米的楼顶掉到水下 11–21 米，隔着十几米水什么都看不见——第一版真实渲染里只剩一栋，就是这么暴露的。现在每栋屋脊落在水面 y=1.12 下方 1.45 米，底板随高度下沉。
- 材质覆盖必须落在**真正的 `MeshInstance3D`** 上（写成 `[node name="<mesh>" parent="Visual" index="0"]` 再持 `surface_material_override/N`）。直接写在 `Visual`（Node3D）上时，单 surface 的旧楼恰好能被引擎的占位重映射救回来，2–3 个 surface 就整组失效——本轮实测过。
- `main.tscn` 的整组替换按**节点块**过滤，不用跨块正则：上一版非贪婪删除只吃掉组头，留下 10 个没有父级的孤儿，Godot 逐个报 `parent has vanished`。
- 专项 `godot/tests/test_submerged_street.gd`：**476 项断言 / 0 失败**。已登记进 `scripts/run_verification.py`（`submerged-street` 与 `visual-submerged-street`）。

## 二、返工（9 条，都来自实际渲染/surface 观感）

| 现象 | 原因 | 处理 |
|---|---|---|
| 水面下看不到十栋，只剩一两栋 | 底板齐平，矮楼顶沉到水下十几米 | 改为屋顶对齐水面（见上） |
| 俯看图里十栋像一片匿名浅色瓷砖 | 屋面是一整块板，没有任何屋顶设备；而水下看街区**主要就是看屋顶** | 新增 `roof_kit()`：楼梯间＋四腿水塔＋两台空调＋通气管＋天线，L 形楼与普通公寓各一套 |
| 底商门洞渲染成纯黑方块 | 底层窗格与门**同平面重叠**（窗在门平面前 0.3 米），z-fighting | 跳过落在门位上的窗格；L 形楼 `(0,5)`、普通公寓 `(0,1)(0,2)` |
| 高架桥断口悬空一根横梁 | 桥底梁按固定 4.2 米节距排，两根正好跨过断口 | 梁位改为显式坐标，全部落在完好段内 |
| 塌落桥面像漂浮薄板 | 悬在水中，下方无支撑 | 在低端加阶梯状塌落堆到海床，堆顶停在桥面下方 |
| 瓦砾散在水中间 | 弃料 z 给的是 0.45 米固定值，与断面高度无关 | 全部贴海床 |
| 路牌拍出来是斜的、像歪招牌 | 该栋在街里旋转 90°，而逐栋相机固定用世界轴 | 相机改为按实例朝向取景（正面偏 24°） |
| 街面人视图取不到十栋 | 街长 67 米，一个 30mm 画面装不下 | 拆西/东两段各拍一张，各段独立做框内断言 |
| 渲染背景是纯蓝，小件像悬空 | 棚拍没有海床 | 加 `海床_展示` 平面（走同一 `add()` 路径，带 PaletteUV 与角色材质，仍在 `展示支持_不导出` 里，不进包、不导出）；颜色用 `gray` 而非 `sand`——大面积浅色平面把整帧照亮到发白 |

## 三、新增的检查（都是从缺陷长出来的）

1. **渲染像素级黑块断言**（`BLACK_PIXEL_LIMIT = 0.15%`）：逐张渲染统计纯黑像素占比。逐面审计抓不到"两块板在**不同**平面共面"的情况——L 形楼那块黑板 UV、材质、面面积全部合规，只有读像素才看得见。这条检查上线后立刻又抓出普通公寓的门（0.294%），两处修完最差一张 0.077%。
2. **屋顶设备回归**：`roof_kit()` 之后，屋面不再是单一大面；配合已有的"近黑大面"与"共面重合面组"检查。
3. **街景两段取景的框内断言**：每段用自身包围盒投影到 NDC 校验，避免"相机偏了但没报错"。
