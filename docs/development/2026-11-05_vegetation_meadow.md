# 2026-11-05 宽叶草地、天台草堆与可见阵风

归属 SEA-AMBIENT-R18 / SEA-ASSET-R51。[制作与复用](../features/ambient/vegetation_meadow.md) · [独立植被账本](../../assets/registry/ledgers/vegetation.json)。

用户指出v002草叶过碎、草地太小、远景不明显，并补充允许在截图中的顶层牧场天台摆草堆，要求草地与草堆都有明显的风吹动态。本轮保留阳光房原有花草，调整两处共享草皮，并按新范围加入天台面片草堆。

## 实际交付

- Image-2重新生成宽叶图集：每张草扇约9–12片较大曲叶，降低细碎叶脉与高光。原生成图、描述、透明裁切与留边处理均保存在`art_source/vegetation/v003/`。
- 草簇载体增至约0.74米宽、0.48米高，仍仅18三角面；实例草高约0.38–0.54米。与v002相比，载体宽约2.5倍、实例高度约2倍，单叶也更宽。
- 草堆由42张分段贴图面片交叠构成，总252三角面、约2.96×2.42×1.13米；空的圆润分布框架，不含实体内核。14处实例沿天台空地和边缘布置，逐顶点复核道路/设施预留区无侵入。
- 阳光房272大草簇＋保留的122苔藓；天台5358草簇＋14草堆。阳光房原56株植物的AssetID、根位置继续通过契约检查。天台旧90草/160细草仅隐藏并保留稳定路径、几何及原Transform，新草不与它们重复绘制。
- 风强度默认1.1，草/草堆位移参数0.20/0.30米；根固定、顶端渐强，同方向空间阵风约2.77米/秒传播，小幅叶尖细动。法线随弯曲改变，远景轻微受光起伏辅助读取；动态主体是GPU顶点形变。
- Standard近/中/很远草密度为100%/80%/45%，不再清空远草；苔藓和草堆保留。共享风时钟、空间分块、暂停和World显隐、无细草阴影继续生效。

资产管理：草沿用`SEA-VEG-GRASS-SOFT`，当前源更新v003并保留v002 previous_sources；新增`SEA-VEG-MOUND-SOFT`与`SEA-TEX-VEGETATION-MEADOW-ATLAS`。原苔藓及原v002图集保留。全部主记录仍由vegetation分账本唯一拥有，三件当前变更有独立源/优化源或贴图处理记录。旧组装工具增加退役保护，避免覆盖v003。
