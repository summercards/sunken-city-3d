# 正式小船转向、加速划桨与贴墙脱困

正式 Main 继续使用方向键或 WASD 按镜头方向划船。开阔水域基础转向上限从 1.8 提到 2.8 弧度/秒，起转加速度从 4.6 提到 8.0 弧度/秒²。低速也能更快建立转速，进入泊位或近期接触附近时用原微调参数。持续旋转按最多 0.03 弧度分段检测船壳。

按住 Shift 与方向键时，普通巡航上限乘 1.5，推进加速度乘 1.45。靠近泊位时从 4.5 米内逐渐收掉加速档，近泊位及近期接触时使用普通速度。放开 Shift 后用原制动过渡，未输入方向时进入滑行停船。

船头转不过去时，先朝输入方向低速扫掠。若受阻，再尝试输入方向中的可用分量和墙面切向。每步检查完整凸壳与落点净空。脱困方向维持到船头对准或玩家改向，避免船头刚能转动一帧就停掉滑移。

加速划桨沿用同一相位，满出力时桨频从 1.1 提到 1.4 桨/秒，水平桨幅从 0.06 提到 0.11 弧度。桨叶摆幅与躯干摆幅一同增加，手掌和骨盆仍以实物挂点解算。
