# 2026-11-04 · 桨架前移与手臂扭转修正

用户指出上一版手臂仍扭转，要求将船桨移到角色前面或让人物后坐。本轮选择前移船桨，归SEA-MOVE-R19 / SEA-NAV-R14；角色坐点保持，不改人物比例、骨架/蒙皮、玩法根、航速或存档。

## 实际修改

- 桨转轴与桨架从船局部z=0.36前移至0.55m，即沿角色面向的+Z移动19cm。转轴y=0.62m，桨架y=0.60m；桨架仍固定在船舷。
- 保持上一版82%桨长，实例轴向偏移从±0.300330改为±0.210330m，让握柄向舷内补9cm。中排座点 `(0,0.6025,0.32)` 保持，未靠后坐造成新的小腿穿板。
- 摆动幅度从0.17改0.06rad，划动倾角从0.28±0.24改为0.36±0.14rad，让拉桨/回桨/转向/停船的手掌都在肩前。
- 上一版两段各自使用“向下→目标”的最短弧旋转，虽到点却带入不同的轴向滚转。现在上下臂共用同一肘轴，前臂只绕该轴弯曲；保留轴的连续方向，不能因世界X符号改变就翻轴。
- 上臂允许自然小幅后摆（≤35°），肘弯≤140°；不强制肘始终在肩前，避免为满足单一投影位置而让弯曲面翻转。必须同时检查握点位于肩前、前臂无轴向扭转、逐相位连续和真实近景。
