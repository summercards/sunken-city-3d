# 2026-11-13 · 工坊交互人性化与配色可用性修复

## 用户反馈

- 配色功能不易使用，点击后看不到明确反馈。
- 所有编辑功能需要再次深度检查。
- 操作完成但没有明显提示。
- 下方提示文字需要高亮并支持复制。
- UI文字偏小，难以阅读。
- 点击和生成后的反馈速度、等待过程不清晰。
- 结构、配色等模块不应依赖下拉框进入。

## 实施

### 模块导航

- 左侧原有模块下拉框保留为兼容状态。
- 新增可见模块按钮组：结构、门窗、配色、破旧、植物、空间、构架、形体、文件。
- 当前模块使用金色边框和深色高亮背景。
- 使用 `HFlowContainer`，窄屏时允许换行。
- 真实模块按钮不再要求用户打开下拉菜单。

### 配色操作

原问题：自动模式下点击色格只刷新高亮，不会切换手动，也不会产生颜色提交，用户会感觉色格不可用。

现在：

1. 在自动模式直接点击任意色格。
2. 自动切换到手动模式。
3. 写入对应 `[row, column]`。
4. 进入实时预览队列。
5. 底部提示显示“已选择色格，正在实时预览”。

色格按钮同时放大，tooltip 增加坐标、色格编号和实时预览说明。

### 状态反馈

底部普通 Label 改为高亮 `PanelContainer`：

- 蓝青色：成功/普通反馈。
- 金色：等待、排队、正在生成。
- 橙红色：失败、输入不合法、需要修正。
- 新增“复制提示”按钮，复制当前完整状态文本。

耗时操作分阶段反馈：

- `预览排队中…`
- `正在生成预览…`
- `参数已实时预览`
- `[警告] ...`

### 字号与布局

- 关键 Label 最小字号提高到16px。
- 按钮、选项、开关字号提高到18px。
- 滑条读数提高到15px以上。
- 主生成按钮提高到300×54。
- 左右栏最小宽度扩大。
- 中央预览最小宽度扩大。
- 模块按钮和复制提示按钮增大。
- 配色色格从23×23放大到30×30。
