# 2026-11-13 · 工坊全量滑条与专属界面主题

## 用户目标

- 优化场景工坊交互和操作手感。
- 所有子功能的数值参数统一使用拉条，不再依赖可键入的数字框。
- 工坊界面颜色与 Godot 系统界面区分。

## 实施

### 全量数值滑条

编辑器主屏 `godot/addons/building_workshop/editor_screen.gd` 与运行版 `godot/src/workshop/panel.gd` 的数值控件统一为 `HSlider`：

- 结构：宽度、进深、楼层、层高、墙厚、板厚、柱宽。
- 门窗：基础窗、开间、门尺寸、楼层/立面覆盖、架构窗、屋顶结构参数。
- 破旧：老化、破损、倒角段数、倒角宽。
- 植物：密度、三档生长权重、随机幅度、种子。
- 空间：收分与结构/破损/植物种子。
- 构架、形体、屋顶和槽位 XYZ 偏移。

保留每个原参数的最小值、最大值和步长。滑条旁显示当前值与 `[最小值 – 最大值]`，整数参数显示整数，细尺寸显示 2–3 位小数。`_control_value`、草稿恢复、撤销和保存仍使用 `Range` 统一读取，不改变配方字段。

### 颜色主题

编辑器主屏增加工坊独立主题：

- 背景：`#101b2d` 深海蓝。
- 面板/控件：`#17263b`、`#1d3048`。
- 边框：`#385b7a`。
- 滑轨与填充：`#46c2d7` / `#70e0e8`。
- 当前值、焦点和拖拽钮：`#f1c56b`。
- 说明文字：`#a9bdca`。
- 工坊根节点设置 `cozy_skip`，避免系统 CozyUI 覆盖工坊样式。

运行版原有深色面板同步使用青色滑轨和金色交互重点。

### 操作反馈

- 滑条支持 Godot 原生键盘焦点与方向键微调。
- 门窗、植物、配色继续沿用 160ms 调度、真实预览、拖拽合并撤销和失败回滚。
- 普通结构/形体/破旧/槽位滑条调整后明确提示“点击生成/应用”，避免误以为已自动提交。
- 无效值保持当前输入、最后成功模型和错误提示，不静默缩放。
