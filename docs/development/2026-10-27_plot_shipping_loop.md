## 交付行为

- 太阳房白盖蓝箱原实例 `solar_cabin/074` 移到码头左侧，保留原模型与 AssetID。点击走近后打开出货箱，物品放入/取回经 DailyShipping 公开端口。
- 浅水平台铺独立木板面、六格木框培养土。每格保留 `platform_plot` / `platform_plot:1..5`，独立选择、独立生长、独立存档。
- 点击空格先出现背包中的种子（零库存不列），点击种子袋图标或种植按钮才扣1包播种；种下后再点该格可选浇水，水壶空时可免费补水。已浇水禁用重复操作，不暗中消耗第二份水。
- 新播生菜、番茄、南瓜首熟均为3个浇水日。播种土丘、次晨幼芽、第二晨长叶、第三晨成熟各有外观；湿土变深。缺水停长，不枯死。已有存档作物剩余天数不重置；番茄沿用2日续茬、最多3茬。
- 成熟格直接点击收获入背包；满包时保留地里作物。随后可重新播种。
- 每天07:00收走出货箱鱼和农产品并入账瓶盖；06:59:59不结算，重复观察同一早晨不重复付钱。结算前可以取回，保管仓库不参与出售。
- 商店继续售卖种子，缺钱/满包不扣款，初始80瓶盖和3包生菜种子。货币只改展示名，`coins`与原余额保留。
- 系统提示仍在右上角，最小配置不再弹底部“完成啦”大板。种植选项卡缩为680×500，普通经营页尺寸不变。开始画面保留。

## 接口与存档

`FarmPlot.interaction_requested` → Main注入地格命令 → HUD/PlotActionPanel；场景动作通过`FarmPlot.perform`转给Farm唯一写入者。UI只列查询结果，最终命令重新检查种子、土格阶段、水量与容量；Main同时校验玩家在岸上并位于地格附近。

`ShippingBox.opened`只打开出货界面，不拥有库存。外观仍是原cooler组件，区块Objects中的代理负责交互。`DaySchedule`统一07:00常量，供WorldClock休息、DailyShipping结算与SaveSchema校验使用，避免未来再次改时间时三处不一致。

继续使用根v3与farm v2，不改物品/地格键。已通过世界坐标校验的岸上存档恢复时吸附当前地面高度，旧浅水平台1.25米位置可恢复到新木板1.48米。午夜之后休息到当天07:00，不额外跳过一天。测试均隔离用户数据，未操作真实玩家存档。

前期失败如实保留：新增节点变量类型推断错误（已改为动态节点引用）；测试将蔬菜单价误写为7，现按物品表固定售价6验证；一次真实点击测试首个点击未进入且随后空按钮访问异常，后续增加诊断并防止空引用，独立重跑通过，原因未确认，不据此更改输入判定。旧框架测试还假设“点击即播种”，已改为验证“不扣种子地打开选项，选择后才扣1包”。

收货员目前是07:00自动收货和收据通知，没有新增NPC驶船搬箱动画。雨天不会自动浇水。移动端、手柄、长期经济平衡及真实断电未执行。完整开发配置验证不代替默认最小范围验证。
