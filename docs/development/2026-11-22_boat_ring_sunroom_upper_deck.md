# 船边泡沫与阳光房二楼

对应 SEA-OCEAN-R50 与 SEA-SUNROOM-R23。修正落在正式 Main 使用的着色器与阳光房组件中。

## 船边白圈

船体泡沫原来在每像素的 5.5 米范围判断内计算 `fwidth(d)`。分支边界的相邻像素走了不同路径，导致外圈出现细白线。现在先从水面位置计算屏幕空间宽度，再做半径判断。该调整作用于船体吃水线和邻近碎浪，桨叶水花与尾迹使用各自的计算。

## 二楼承重与梯口

原先修梯完成后只启用梯顶的小支撑盒，角色能走到可见的露台木板上并跌落。现在整片楼板碰撞常驻于阳光房组件，修梯后开放二楼空间查询。梯顶落脚点向露台内移动约 0.23 米，前缘角色阻挡覆盖栏杆和梯口。攀爬使用既有动作越过梯口，修整后显示对应的家具与植被。
