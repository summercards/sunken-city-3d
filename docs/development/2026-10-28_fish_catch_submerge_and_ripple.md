# 可捕捞鱼群：沉到水里去，涟漪压淡减圈

日期：2026-10-28。功能：SEA-PICKUP（条款 SEA-PICKUP-R04）。

[主文档](../../GDD_V1.0.md) · [SEA-PICKUP 文档](../features/pickup/spec.md) · [账本](../features/pickup/ledger.md)

## 用户提出的要求

1. 可捕获的鱼群组件：**波纹的透明度调低一些，少一些**。
2. **鱼往下挪一些，到水里去**。

## 结论先行

两条要求各对应一个缺陷，两个都改，而且第二条改变了这条鱼群的产品定义（从「贴在水面上的靶子」变成「水下的鱼」），所以连带项一起处理：

| 现象 | 真正原因 | 修法 |
|---|---|---|
| 涟漪太亮、太多 | ① 双圈开环 + 两道错相脉冲，一共四条同心弧；② 透明度 0.56；③ **圈色是近白 `(0.76,0.98,0.95)`**——ACES 之后「20% 的白」叠在深蓝水面上仍然是一道亮白环 | 单圈 + 一道脉冲；透明度 0.56 → 0.20；圈色改水青灰 `(0.34,0.58,0.58)` |
| 鱼浮在水面上 | 旧设计是**故意**抬上去的：`RIDE_LIFT = 0.29 + 0.11·SIZE + 0.02 = 0.42`，理由是「低于浪峰会被半透明水膜盖住、颜色发灰」 | 反过来：按**最高点**算沉深（`SUBMERGE = 0.40`），整条压在浪面之下，与水面装饰群同一口径 |

第二条不是把数值改小一点：旧公式的立论是「浮在水面上才不被水膜洗白」，现在要求是「就要在水里」，所以口径必须换 —— 从「鱼心高于浪面多少」换成「鱼最高点低于浪面多少」，半高要乘该条鱼自己的实例缩放（个体 0.92–1.06 浮动），否则大一号的那条会把背脊顶出水面。

## 具体数值

`godot/src/pickups/fish_school_visual.gd`：

| 参数 | 改前 | 改后 |
|---|---|---|
| 贴水方式 | `RIDE_LIFT = 0.29 + 0.11·SIZE + 0.02`（鱼心在水上 0.42 m） | `SUBMERGE = 0.40`（最高点在水下 0.40 m + 个体深度微差 0.015–0.045） |
| 涟漪环数 | 2（0.55 / 0.72 半径） | 1（只留 0.55 内环） |
| 涟漪扩散波 | 2（错相 0.5） | 1 |
| 涟漪透明度 | 0.56 | 0.20 |
| 涟漪圈色 | `(0.76, 0.98, 0.95)` 近白 | `(0.34, 0.58, 0.58)` 水青灰 |

`godot/shaders/surface_ripple.gdshader` 加了三个 uniform：`ring_count`、`wave_count`、`ring_tint`。**默认值全部等于旧观感**，所以共用这片着色器的漂流物资圈不受影响（`make_ripple()` 的默认参数也没变，鱼群才显式传新值）。

`godot/src/pickups/sea_props.gd` 的点击锚点跟着下移：`root.global_position - UP*0.45`（原来 `+UP*0.3`）。鱼整条沉到水下 0.5 m 左右，锚点还在水面上会偏出小半米，影响点选手感。

## 只降 alpha 不够：一次实拍否掉的改法

这是本轮唯一一个「看起来对、实测不对」的地方，记下来免得下次重走：

| 版本 | 圈峰值屏幕色 | 水面基准 | 观感 |
|---|---|---|---|
| 原版（0.56 / 双圈） | `(181,202,205)` | `(143,177,189)` | 一道很实的亮白圆环，压过鱼 |
| 只降到 0.28 / 单圈 | `(181,202,205)` | 同上 | **几乎没变化** |
| 0.20 + 圈色改青灰 | `(152,184,193)` | 同上 | 退成水面上的一丝痕迹 ✓ |

第二行是关键：alpha 减半、环数减半，屏幕上几乎看不出差别。原因在圈色本身 —— 近白叠在深蓝水上，alpha 0.3 和 0.5 的差别被 ACES 的肩部压平了。所以想让它真的退下去，**必须同时压圈自身的亮度**。

## 验证

`scripts/run_verification.py visual-fish-schools --full-world` → **135 checks, failures=0, exit=0**（`20261028-171520-verification-28d3cf`）。

本轮新增 12 条断言：

- 可捕捞群**每条鱼**的最高点沉深落在 0.25–0.90 m（下限锁「确实进了水」，上限锁「没沉成水底暗点、还点得中」）；
- 群内纵深差 ≥ 0.01 m（不是一层平面贴纸）；
- 涟漪 `opacity ≤ 0.35`、`ring_count ≤ 1`、`wave_count ≤ 1`、圈色向量长度 < 1.5（非近白）；
- **涟漪只允许一层** —— `build()` 被调两次会在同一节点上叠出两层 `SurfaceRipple`，两层 alpha 合成后参数怎么调都调不淡。这是「调参不生效」最常见的原因，所以变成会失败的断言；
- **漂流物资的圈仍是 0.56 + 双圈** —— 这次只压鱼群，不许顺手把场景里其他的圈一起调淡。
