# sea 宣传片 v4 —— 90 秒实机玩法展示

- 成片：`promo/renders/sea_90s_1080p60.mp4`（1920×1080 / 60 fps / 90.000 s / H.264 + AAC）
- 素材来源：**全部为当前版本 Godot 工程的实机逐帧渲染**，没有生成画面、没有网页原型截屏
- 录制脚本：`godot/tools/record_promo_90s.gd`（本工程内为 `sea-work/promo90/project/tools/`）
- 隔离工程：`scripts/build_promo_project.py`，用户数据在 Autoload 前改道，不碰正式存档

与 v3（2 分钟）的区别：v3 是「家 → 造 → 走」三幕的风景偏多的版本；v4 按
**观众理解玩法的最优顺序**重排，砍掉空镜，每一段都必须有「为什么做 → 怎么做 → 得到什么」。

## 三、配乐

工程里没有任何音频资产，配乐是**为这条片子现做的合成音轨**（无版权风险，`make_score90.py`）：

- 粉噪低通成海，17 秒与 6.3 秒两条正弦叠成极慢起伏；
- C–Am–F–G 和弦垫，长起音、微失谐，按段落给 0.55–1.0 增益；
- 五声音阶拨弦：8 秒进入，40 秒上八度，**潜水段（56.5–68 s）跳到两个八度外做「气泡感」**，
  并撤掉低音，让水下安静下来；
- 85 秒起低频 drone 淡出，最后一句留和弦尾巴。

峰值 −1.0 dB、均值约 −14.6 dB，首尾各 2.6 s / 6 s 淡入淡出。

## 四、录制方式

不是外部录屏（会带桌面、掉帧、不可复现），用 Godot 自带 Movie Maker 逐帧出图：

```bash
python scripts/build_promo_project.py --run-dir <工程外目录> --width 1920 --height 1080
godot --path <工程外目录>/project --resolution 1920x1080 --fixed-fps 60 \
      --write-movie out.avi --script res://tools/record_promo_90s.gd
```

`--fixed-fps 60` 把时间轴与渲染解耦：每帧固定推进 1/60 秒，机器再慢也不掉帧，
5400 帧严格等于 90.000 秒。
