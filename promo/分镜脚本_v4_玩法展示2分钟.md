## 四、配乐

工程内没有任何音频资产，配乐是为本片现做的合成音轨（无外部素材、无授权风险）：

- 粉噪低通成「海」，17s 与 6.3s 两条正弦叠成极慢起伏；
- C–Am–F–G 长起音和弦垫，按段落给 0.55–1.00 的增益（阳光房段压到 0.66，深沟段 0.86）；
- 四段五声音阶拨弦琶音：24–52s 单声部、52–74s 稀疏、74–104s 加高八度、104–114s 收尾。

峰值 −1.0 dB、均值 −14.7 dB，首尾 2.2s / 5.0s 淡入淡出。

## 五、录制方式

```bash
python scripts/build_promo_project.py --run-dir <工程外目录> --width 1920 --height 1080
godot --path <run>/project --resolution 1920x1080 --fixed-fps 30 \
      --write-movie out.avi --script res://tools/record_showcase_2min.gd
```

`--fixed-fps 30` 让时间轴与渲染解耦，3600 帧严格等于 120.000 秒，机器再慢也不掉帧。
实测录制约为实时的 38%（1080p 全片约 5 分钟）。

隔离口径与 `scripts/run_verification.py` 一致：`custom_user_dir_name` 在 Autoload
之前改写，`assets` / `terrain` / `.godot/imported` 只读挂载，仓库 `project.godot` 不动。

真实驱动：点击开始走 `_enter_game`，修缮走 `Economy.sunroom.repair_ladder()` /
`restore_upper()`，爬梯走 `actor_controller.climb_ladder()`，种植与收获走
`FarmPlot.perform()`，建造走 `building.begin()` + `building.tick()`，下潜走 `_on_dive()`，
NPC 走 `npc_world_presenter.open_npc()`，进商店走 `shop_panel.open_shop()`。

## 六、只有本片才做的会话内调整

全部写在录制脚本里，不进正式代码：

- **船速 ×1.9**：`boat.speed_multiplier` 回调注入，只影响本进程。
- **界面收敛**：逐帧隐藏「视野 x%」浮标与底部操作大卡片。
- **相机锁**：每帧重申目标 / 距离 / 方位，否则跟随逻辑、模态面板、过场 tween 会各自抢走镜头。
- **修梯前隐藏角色**：12–17 秒的主体是梯子，角色先不入画，爬上梯子那一刻再出现（等于一个剪辑切点）。
- **水下直控相机**：深沟只有 40 米宽，跟进相机贴墙会把两侧楼全挤出画外；这一段直接把相机
  架在沟中央沿 +X 平移，两侧楼墙才同时入画。
- **海底地图预热**：`ResourceLoader.load_threaded_request` 在商亭段就发起，否则下潜时
  圆幕会被加载卡黑近 4 秒（第一版实测 3.87 秒纯黑，预热后压到 0.47 秒）。

## 八、已知取舍

- **霓虹花园只有豆豆一个 NPC 入画**。船老大在屋顶另一侧，同框会破坏构图，没强塞。
- **深沟水下没有鱼群**。家园海底的生态集中在阳光房周围，这一圈是空的，靠楼体立面与天光撑。
- **礼品商亭室内是剖切视角**。相机在建筑内时墙体按视线方向自动收起，所以看到的是「剖开的店」，
  不是真实从门口走进去的第一人称。
- **没有拍顶层牧场与横滨铁道**。这条片子的时长预算给了本周更新，这两处上一版已经展示过。
