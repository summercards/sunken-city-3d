# sea 宣传片分镜脚本 v1

- 生成工具：04 号机 ComfyUI + MiniMax H3（t2v / fl2va 底模）
- 单镜时长：5 秒（24fps / 124 帧）
- 画面基准：864×480 出片 → RealESRGAN 放大到 2K
- 全片风格锁定：治愈系水彩、纸纹质感、低饱和暖色、水下焦散、无战斗、无文字 UI
- 拼接后总长：约 50 秒（10 镜 × 5 秒）

## 0. 全片统一风格前缀（每条 prompt 都要带）

> 治愈系水彩动画风格，手绘纸纹质感，低饱和暖色调，水下柔和焦散光斑缓慢流动，画面静谧有呼吸感，无人物面部特写、无战斗、无文字与 UI；镜头运动缓慢平稳。

## 2. 逐镜 Prompt

### 01 沉没的世界
```
治愈系水彩动画风格，手绘纸纹质感，低饱和暖色调，水下柔和焦散光斑缓慢流动。镜头在水下缓慢上浮：四周是被海水淹没的旧城市高楼，玻璃窗破碎、楼体覆着藤壶与海藻，成群小鱼从窗洞穿过；远处一道巨大的鲸鱼剪影缓缓游过，光线从水面斜射下来形成柔和的丁达尔光柱。镜头越过屋顶边缘浮出水面，水面与天空在画面上缘展开。画面静谧有呼吸感，无人物、无战斗、无文字。镜头运动：缓慢平稳连续上浮，水波自然扰动。
```

- 05–06：从一块木板，到一艘船。
- 07–08：海水之下，还有更远的地方。

## 4. 生产建议

1. 先用 01、02 两条验证风格（864×480 / 5s，约 3–6 分钟一条）。
2. 风格确认后批量跑完 10 条，seed 固定便于复现。
3. 出片后用 RealESRGAN 放大到 2K，再统一调色 + 拼接 + 加字幕与音乐。
4. 若某条镜头不理想，只重跑该条，seed 换 ±1。
