# sea 宣传片 v3 —— 2 分钟实机（120.0 秒）

- 成片：`promo/renders/sea_promo_120s_1080p.mp4`（1920×1080 / 30fps / 120.000s / H.264 CRF19 + AAC 192k）
- 轻量分享版：`promo/renders/sea_promo_120s_1080p_share.mp4`（CRF25，约 45MB）
- 素材来源：**全部为游戏当前版本的实机逐帧渲染**，不是 AI 生成画面、不是网页原型
- 录制脚本：`godot/tools/record_promo_2min.gd`；隔离工程构建：`scripts/build_promo_project.py`

与 v1 / v2 的区别：v1 是 60 秒纯风景，v2 是 AI 分镜（沉没城市 → 重生），
v3 不再用生成画面，改成**按真实玩法链路组织**的实机片，观众看到的就是玩家会看到的东西。

## 三、配乐

工程内没有任何音频资产，所以配乐是**为本片现做的合成音轨**（无版权顾虑）：

- 一层粉噪低通成「海」，17 秒与 6.3 秒两条正弦叠成极慢起伏；
- 一层正弦叠加的长起音和弦垫，C–Am–F–G 循环，按段落给 0.55→1.0 的增益；
- 三层五声音阶拨弦琶音，26 秒进入、76 秒加高八度、112 秒收掉。

峰值 −1.0 dB、整体均值 −14.6 dB，首尾各做 2.2s / 4.8s 淡入淡出。

## 四、录制方式

不是外部录屏（会带桌面、会掉帧、无法复现），用 Godot 自带 Movie Maker 逐帧出图：

```bash
python scripts/build_promo_project.py --run-dir <工程外目录> \
    --width 1920 --height 1080
godot --path <工程外目录>/project --resolution 1920x1080 --fixed-fps 30 \
      --write-movie out.avi --script res://tools/record_promo_2min.gd
```

`--fixed-fps` 让时间轴与渲染解耦：机器再慢也不掉帧，3600 帧严格等于 120.000 秒。
实测录制速度约为实时的 40%，全片约 5 分钟出 1080p 母版。

隔离方式与 `scripts/run_verification.py` 一致：用户数据在 Autoload 之前重定向到
`sea-promo/<run>`，资产与导入缓存以目录联接只读挂载，仓库 `project.godot` 不改，
只把 viewport 从 1600×1000 改成 1920×1080。

## 五、只为这段素材做的会话内调整

全部写在录制脚本里，**不进正式代码，不改任何玩法数值**：

- **船速 ×2**：`boat.speed_multiplier` 回调注入，只影响本进程。真实航段十几秒太慢
- **隐藏「视野 x%」浮标**：逐帧调机位会把它刷成常驻提示
- **隐藏底部操作大卡片**：角色站定时常驻，会盖住构图
- **相机锁**：每帧重申一次目标/距离/方位，防止跟随逻辑、模态面板、过场把镜头抢走
- **生长延时**：`farm.debug_set_growth` 分 16 步推进，这是既有的预览命令
- **建造施工**：`building.tick(0.11)` 分 30 帧推进，能看到 ghost 转实体

## 六、已知取舍

- **水下段偏暗**：家园海底的旧城在 56 米深度，原始画面接近黑色。成片里对 87.4–97.8 秒
  做了 `brightness=0.045 / gamma=1.14` 的轻度提亮。大幅提亮会发灰起雾，试过一版放弃了。
- **水下没有鱼群**：家园海底的生态分布集中在阳光房周围，旧城街区那一段是空的。
  这一段靠建筑立面和天光撑，不靠生物。
- **下潜有 1.5 秒纯黑**：这是游戏本身的圆幕过场（`合拢 0.85s → 全黑 → 打开 1.05s`），
  没有剪掉，因为它是玩家真实看到的东西。
- **送礼亭 / 霓虹花园 / 顶层牧场没进片**：这三处要么是封闭主体、要么机位不好，
  拍出来是空白海面或只见墙面。宁可不拍。
- **UI 全部保留**：这是一支「玩法演示」片，HUD、面板、气泡都是内容的一部分，
  没有做去 UI 处理。
