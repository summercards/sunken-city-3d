# 与正式阳光房一致的建筑尺度

适用于sea海上生活建筑的新建及同族改造。基准是正式`solar_cabin`的v008运行装配，2026-10-31由Godot探针量取真实MultiMesh网格及逐实例世界变换；不是Blender未缩放尺寸或凭截图估算。机器数值和来源见[building_scale.json](building_scale.json)，项目证据为`docs/development/2026-10-31_sunroom_dimension_probe.json`。

| 量 | 默认值（最终游戏米制） | 口径 |
|---|---:|---|
| 底层净高 | 4.866335 | 主地板顶面到上层楼板底面；主承重柱同高 |
| 底层层高 | 5.086335 | 下层地板顶到上层地板顶，含0.22米楼板 |
| 楼板、露台板、主要木铺板厚 | 0.220000 | 实体厚度，不是在厚承台上加一层薄皮 |
| 门框整体高×宽 | 3.070845×1.828500 | 现有door资产世界包络，**不是已量出的净门洞** |
| 底层主柱截面 | 0.517500×0.517500 | 不能将装饰压条当承重柱来替代 |
| 上层装饰柱截面/高度 | 0.388125 / 3.094650 | 现有上层小体量变体，不替代底层主柱基准 |
| 主平台板宽/节距/净缝 | 0.893551 / 0.920000 / 0.026449 | 板长由新建筑决定，板宽厚与节奏沿用基准 |
| 栈桥板宽 | 0.750376 | 现有桥面变体；厚度仍0.22米 |
| 屋顶露台板宽 | 0.780131 | 现有露台变体；厚度仍0.22米 |
| 地板顶离水面 / 板底离水面 | +0.26 / +0.04 | 与0.22米楼板一致，不能沿用旧厚板必须沉水的断言 |

新造型保持统一尺度与结构感；长宽和屋顶样式可设计，不要求复制阳光房外形。无门窗的建筑只引用门框标准作为比例参照，不为满足表格擅自增加门窗。净高与层高分别记录；斜屋顶、设备高度、女儿墙不计作新一层净高。圆角、板缝、木色也应与阳光房同级，避免细针柱、薄皮木板或过密地板条造成另一套风格。

运行米制以Godot最终网格与逐实例变换为准。`sunny_bloom_visual.gd`会按组件分组装成MultiMesh；`mesh.get_aabb()`本身不含每个实例的倍率，使用`global_transform * instance_transform * local_aabb`。只采`Models/太阳能木屋/太阳能木屋-海上区域`，避免把海下基座同名wall_pier混入。底层柱、上层装饰柱、长侧连墙件分别筛选，不能把整个合并包围盒叫柱截面。

若正式阳光房换版，用`python -X utf8 scripts/run_verification.py building-scale-reference --label sunroom-scale-reference`重新采集，核对实例清单哈希和稳定组件来源，再更新机器表及这份说明。所有运行探针走统一runner隔离用户数据；不要直接跑玩家档。对新资产核查实际木板宽厚、主柱截面、净高和楼板厚，保存重开后再比较；运行图将新建筑与阳光房同屏核对，不凭独立棚拍认定风格统一。
