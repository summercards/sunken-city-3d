# 风格化形体语言（零方正）

对象：海上主场景中一切可见的建筑件。船、独立植物、纯水下远景不适用。

数值单位=最终游戏米制。只描述形体；净高／层高／板厚／柱粗／倒角档位／四材质角色仍由
[SKILL.md](../SKILL.md) 与 [building_scale.json](building_scale.json) 拥有，本页不得覆盖。

机器表：[stylized_form_variants.json](stylized_form_variants.json)。校验：`scripts/check_stylized_form.py`。

---

## 1. 唯一原则：不许有方形，不许有直筒

**任何有体量的构件，上下必须不对称。** 没有"这一件是默认方正的"，没有"整体工整所以可以不做"。

判定只有一条：**把这一件单独拎出来，轮廓会读成方盒或直筒吗？会 → 必须改。**

| 判定 | 处理 |
|---|---|
| 能读出体量轮廓（墙、柱、楼板、窗、门、水塔、招牌、顶棚、箱、盆、桶、缸、杆） | **必须带上下不对称**，`1% ≤ \|ρ\| ≤ 10%` |
| 贴片、线缆、螺栓、把手、铰链、平面图形、纯贴附薄板（厚度 ≤ 0.02） | 不构成体量，**可豁免**，但必须写 `no_volume: true` 且**必须倒角** 0.008–0.02 |

**ρ = 0 一律失败。** 不是"建议改"，是不通过。

### 1.1 那"工整"怎么办

工整**不靠"大部分件不做"，靠两件事**：

1. **同族同向。** 同一栋里的结构族（墙、柱、楼板、檐口）必须用**同一个符号**——要么都上小下大，要么都上大下小。墙各向一处歪、柱一会儿粗一会儿细，那才是"在歪"。
2. **幅度克制。** 结构族用 1%–3%，肉眼几乎不察；但 6 米宽的墙上口窄 6cm 就足以消掉直筒感。风格件 2%–8%，独立体 6%–10%。

**"工整" = 方向一致 + 幅度小 + 直角不倒置，不是 = 方正。**

### 1.2 为什么不是"挑几件做"

上一版写过"挑 15%–30% 的件做形体"，实测结果是：一栋 45 件的房子只补了两件，剩下 43 件全是方盒，渲出来整体是方块搭的。**局部改动救不了整体观感——方盒的数量决定观感，不是风格件的数量。**

所以本版取消筛选比例，改为**零方正**：分母是全部体量件，目标是 0 个方盒。

## 2. ρ 口径

```
ρ = 1 − 上口尺寸 / 下口尺寸      正 = 上小下大（正梯形/收分）；负 = 上大下小（倒梯形）
```

- **按对应边长计，不按面积计。** 边长差 10% 对应面积差约 19%，按面积算会误判超限。
- 声明轴向：`z`（竖向体量）／`x`（横向面宽）／`y`（进深）。每件取一个主轴向。
- **1% 是可读下限**：1080p、机位 20 米时，6 米宽件上下差 1% = 6cm ≈ 2 像素，刚好看出不是直筒。低于 1% 等于没做，仍判失败。
- **10% 是绝对上限**：超过就成锥塔，工整感直接崩。
- 沿高度线性时 `上口 = 下口 × (1 − ρ)`；逐层累计 `W_n = W_base × Π(1 − ρ_i)`。

与结构基准的耦合：

```
墙面倾角 β = atan(|ρ| · W_base / H_floor) ≤ 4°
可用 ρ 上限 = tan(4°) · H_floor / W_base = 0.0699 · H_floor / W_base
```

净高 4.9、墙宽 6.0 时上限 0.057。**10% 是语法上限，结构倾角是物理上限，取小的那个。**
墙越宽、层越矮，可用收分越小；超了就换轴向改 `y`（进深），不硬收横向。

## 3. 各族的 ρ 与符号

结构族同向（第 1.1 节）；非结构族需正负共存，避免全栋变金字塔或喇叭塔。

| 功能族 | 典型件 | 轴向 | ρ 带 | 符号 | 说明 |
|---|---|---|---:|---|---|
| 墙壳／楼层体量／基座 | 墙、楼板、平台 | z / y | 0.01–0.03 | 结构族统一 | **必须做，不许为 0**；小到像"手工砌的"，不像"锥形" |
| 竖向结构 | 柱、栏杆立柱、门框 | z | 0.02–0.05 | 结构族统一 | 柱是直筒重灾区，必须变径 |
| 水平覆盖 | 楼板、屋面、檐口、顶棚 | y | 0.02–0.05 | 可与结构族不同 | 前缘比后缘窄，沿出挑方向收 |
| 开口 | 窗、门洞、通风口 | z | 0.015–0.04 | 同结构族 | **梯形窗**：上口略窄于下口，玻璃随之梯形，不做正交矩形 |
| 独立体 | 水塔、烟囱、箱体、花池、桶、缸 | z | −0.10–−0.06 | 负 | 倒梯形是识别度主体；水塔罐体尤其不能直筒 |
| 平面贴附 | 招牌、海报、铭牌 | z | 0.015–0.04 | 正 | 配合第 4 节倾斜 |
| 线性构件 | 杆、管、扶手、柱身细部 | — | 径比 ≤ 0.953 | — | `ρ = 1 − d_top/d_bottom ≥ 0.047`；圆柱**必须**变径 |

**圆柱专条**：栏杆、管、杆、灯杆、天线杆最容易做成直筒。要求 `d_top / d_bottom ≤ 0.953`
（即 ρ ≥ 4.7%）。低于这个值肉眼读成直筒，判失败。

### 3.1 锥度方向：沿最长轴渐变，改变截面

**锥度必须沿构件的最长轴渐变，被缩小／放大的是垂直于它的截面尺寸。长边本身长度不变。**

```
taper_along = argmax(extent_x, extent_y, extent_z)
被改的尺寸   = 垂直于 taper_along 的截面（两条，按同一比例）
```

为什么：同样的 2%，落点不同，观感差一个数量级。

| 件 | 包络 | 沿最长轴 | 改截面 | 绝对改变量 | 角度 |
|---|---|---|---:|---:|---:|
| 主招牌 | 9.09 × 0.47 × 2.28 | **x（9.09）** | 2.28 → 2.223 | 5.7cm 摊在 9 米上 | **0.36°** ✓ |
| 主招牌（错法） | 同上 | z（2.28） | 9.09 → 8.91 | 18cm 摊在 2.28 米上 | **4.5°** ✗ |
| 墙壳 | 8.6 × 8.2 × 10.0 | z（10.0） | 8.6 → 8.43 | 17cm 摊在 10 米上 | 0.98° ✓ |
| 主柱 | 0.5 × 0.5 × 4.9 | z（4.9） | 0.5 → 0.485 | 1.5cm 摊在 4.9 米上 | 0.18° ✓ |
| 带栅窗 | 7.60 × 0.29 × 3.55 | x（7.60） | 3.55 → 3.479 | 7cm 摊在 7.6 米上 | 0.54° ✓ |
| 檐板 | 9.10 × 0.21 × 0.96 | x（9.10） | 0.96 → 0.941 | 2cm 摊在 9 米上 | 0.12° ✓ |

**错法的后果就是那张截图**：牌子左右边不平行，人眼立刻读成"歪的、做坏的"，不是"手作的"。
沿最长轴渐变时，两条长边仍是直的、几乎平行，只是上下沿之间有个 0.3° 的收敛——正好消掉"塑料方盒感"。

长度并列（正方平面）时任选一轴即可，脚本按"该轴尺寸等于最大值"判定。

## 4. 倾斜

```
绕底部接触边旋转；旋转后最低点 ≥ 支撑面 + 0.005
相邻件间隙 ≥ 0.01；旋转后包围盒沿面法向不得越过墙面
```

| 件 | 倾角 γ | 方向 |
|---|---|---|
| 招牌／灯箱／目录板 | 4°–10° | 绕底边，同栋不重同一角度 |
| 顶棚／遮阳篷 | 2°–6° | 侧倾；出挑下倾另记 `pitch`（26°–36°） |
| 靠墙板／梯 | 6°–14° | 顶部离墙，底部贴墙 |
| 箱盖／活板 | 20°–30° | 单边抬起 |
| 门板 | 0°–6° | 不超过铰链可开角 |
| 空调外机／电箱 | 2°–5° | 左右微歪，不做前后倾 |

单件上限 **12°**（箱盖 30° 是唯一例外，属状态件）。同栋相邻两件角差 ≥2°。

**倾斜强制**：倾斜件数 `≥ max(1, ⌈挂件数 × 30%⌉)`。全楼没一件歪，等于把"生动"那半丢了。

**倾斜只给挂件。** 墙、楼板、主柱、水塔罐体、楼层体量不许倾斜——结构件的摇摆感靠 ρ 做，
不靠旋转，旋转会毁掉直角与楼板水平。

## 5. 嵌入层次

层次做两件事：让面不再是平面，让转角有咬合。**层数 ≤3**。

```
砖层：块高 h_b ∈ [0.25, 0.40]，块长 L_b ∈ [0.50, 0.60]，突出 e_b ∈ [0.03, 0.08]
      错缝 offset = 0.5 · L_b，行间深浅交替 e_b × (1 ± 0.30)
隅石：突出 e_q ∈ [0.08, 0.16]，长块:短块 = 1.6:1.0，竖缝 g ∈ [0.02, 0.04]
      块对 n ≈ H_wall / 1.2（H=4.9 → n=4），顶块斜切 30°
檐口：三层叠涩，O1:O2:O3 = 0.45:0.33:0.22，总出挑 O ≤ min(0.45, 2.25×板厚)
```

突出量硬限 `e ≤ 0.8 × 该处墙厚`。0.2 米墙 → 上限 0.16，隅石顶格，砖只能是它一半。

**嵌入强制**：`relief` 至少一种真实几何（`quoin_blocks`／`brick_blocks`／`grooves`／`brackets` > 0）。
只写 `layers: 1` 却一块没做，墙面还是平面，判失败。确实不做必须登记 `relief_waived_reason`。

**砖嵌只做前立面可见 1–2 面、前 2 米高度**，其余用换色格暗示。整栋铺满既爆面数也毁工整。

**面数陷阱**：逐块嵌入 188 tri/块，6 米墙 24 块 = 4512 tri。低面替代：整片墙挤出凹槽（每槽 3 面）。

## 5.1 接缝：不许共面，不许穿模

两件挨在一起时只有四种合法做法：

| relation | 含义 | 要求 |
|---|---|---|
| `inset` | 宿主开槽，子件嵌进去 | `gap_m` 2–20mm |
| `clearance` | 两件之间留实缝 | `gap_m` 2–20mm |
| `boolean_cut` | 宿主开洞，子件从洞里过 | `cut_verified: true`，且洞里无残留面 |
| `miter` | 斜接（两件 45° 对拼） | `gap_m` 2–20mm |

**五种禁止**：

| 禁止 | 后果 |
|---|---|
| `coplanar` 共面 | 深度冲突，着色闪、渲染出横纹 |
| `face_to_face` 面贴面 | 同上，且拆件时互相切 |
| `interpenetrate` 穿插 | 交界处一条假交界线，优化/拆件必出错 |
| `overlap` 重叠 | 同上 |
| `flush` 齐平 | 既无缝也无槽，读作两块板叠着 |

`gap_m` 下限 2mm：小于这个数，1 米外看仍是共面。上限 20mm：再宽就要改成开槽或布尔，否则像拼装玩具。

**"整个结构出来"**：贴在墙角的梯子，不要做成"一个墙面 + 一个梯子盒子"叠在一起。把转角柱当成梯子的宿主——
柱面开两条竖向凹槽，竖杆嵌进槽里、横档两端插进杆上的孔，形成真实接缝。这样：

- 没有共面：杆在槽内，档在杆内
- 没有穿模：所有接触都发生在槽／孔里
- 那根柱也被读懂了：它是梯子的支座，不是多余的方块
- 面数更省：开槽每槽 3 面，比"重做一整件"便宜，也比"贴合"更省后续返工

**附着件必须登记**：任何写了 `attached_to` 的组件，必须在 `contacts` 里有一条对应记录。没记录 = 你不知道它到底是怎么接上去的，验收不通过。

**这不是"高模才讲究"的问题。** 共面在引擎里是深度冲突，穿模在优化（合并、decimate、碰撞派生）时必然出错。
省下的那点建模时间，会在接入阶段加倍还回去。

## 6. 表面：只有换色格，没有贴图通道

sea 只有四个共享材质角色加一张纯色板，**没有 albedo 贴图通道**。掉漆、锈迹、污渍流挂一律复刻不了。

允许三种表达：换色格、4–7 边薄贴片（厚 0.010–0.020、凸 0.004、每面 ≤3 片）、
几何缺口（2–5 边，深 0.02–0.06）。覆盖率合计 ≤ 上限（2%／3.5%／5%）。

**不借用**：锈迹色、暗沉灰调、破损玻璃、街头垃圾堆、污渍流挂。生活感用整齐摆放的小件表达。

## 7. 面数与预算

| 元件 | 三角面 |
|---|---:|
| 3 段倒角方块 | 188（实测，见 [building_scale.json](building_scale.json) 的 `bevels.source_evidence`） |
| 逐块砖嵌（单块） | 188 |
| 整片凹槽墙（单槽） | 3（底＋两侧）＋两端封口 2 |
| 12 边圆柱杆件 | 48 |
| 薄贴片（4–7 边） | 6–10 |

```
ΔT ≈ 188 × (N_quoin + N_bracket + N_brick_3d) + 3 × N_groove + 48 × N_brace + 8 × N_patch
```

造型增量上限 **主体三角面的 35%**。超了先换整片凹槽，再减可见转角，最后才减嵌入范围——
**永远不要用"把 ρ 改成 0"来省面**，那等于放弃本语言。

**锥度本身不花面数。** 方盒改锥台只是移动顶点，三角面完全不变。所以"零方正"不增加预算，
只增加建模工时。这条要写死，否则下一轮又有人说"面数不够所以做方正"。

实测参考（墙宽 6.0、墙高 4.9、墙厚 0.2、板厚 0.2、檐口长 8.0、四角）：

| 档位 | 隅石＋托架 | 增量 | 说明 |
|---|---:|---:|---|
| SF-A | 24 + 11 | 6580 | 克制，补件用 |
| SF-B | 32 + 14 | 8648 | 标准 |
| SF-C | 40 + 17 | 10716 | 强风格，仅远景地标 |

## 8. 三档强度

档位只调**幅度与密度**，不改第 1 节"零方正"——任何档位都不许出方盒或直筒。

| 参数 | SF-A 克制 | SF-B 标准 | SF-C 强风格 |
|---|---:|---:|---:|
| 结构族 ρ | 0.01–0.02 | 0.015–0.025 | 0.02–0.03 |
| 开口 ρ（梯形窗） | 0.015–0.025 | 0.02–0.03 | 0.025–0.04 |
| 风格件 ρ | 0.02–0.05 | 0.03–0.06 | 0.04–0.08 |
| 独立体反锥 | −0.06 | −0.08 | −0.10 |
| 杆件径比上限 | 0.970 | 0.953 | 0.930 |
| 隅石突出 e | 0.08 | 0.12 | 0.16 |
| 隅石块对 n | 3 | 4 | 5 |
| 檐口出挑 O | 0.28 | 0.36 | 0.45 |
| 托架间距 p | 0.75 | 0.60 | 0.50 |
| 山花峰高比 | 0 | 0.12 | 0.16 |
| 水塔高径比 k | 0.45 | 0.55 | 0.62 |
| 篷条数／下倾 | 7／26° | 9／32° | 11／36° |
| 挂件倾斜 γ | 4°–6° | 6°–9° | 9°–12° |
| 贴片覆盖 | 2% | 3.5% | 5% |

默认 **SF-B**。SF-A 给贴现有阳光房的补件，SF-C 只给远景地标。

## 9. 验收

```bash
python3 .agents/skills/sea-scene-component-authoring/scripts/check_stylized_form.py --plan <该版本>/component_plan.json
python3 .agents/skills/sea-scene-component-authoring/scripts/check_stylized_form.py --selftest
```

逐件核，**全部是硬断言**：

| 断言 | 内容 |
|---|---|
| `no_square_volume` | 每个体量件 `1% ≤ \|ρ\| ≤ 10%`；ρ=0 判失败 |
| `cylinder_taper` | 杆／管／柱 `d_top/d_bottom ≤ 档位上限`（默认 0.953） |
| `sign_consistency` | 同栋结构族符号必须一致；非结构族必须正负共存 |
| `tilt_coverage` | 倾斜件数 ≥ `max(1, ⌈挂件数×30%⌉)` |
| `tilt` / `structural_tilt_forbidden` | 倾角 ≤ 类目上限；结构件不许倾斜 |
| `relief_presence` | 隅石／砖嵌／凹槽／托架至少一项 > 0，或登记豁免 |
| `relief_protrusion` | `e ≤ 0.8×墙厚` 且在族带内 |
| `wall_tilt` | 结构族倾角 β ≤ 4° |
| `tri_budget` | 造型增量 ≤ 主体 35% |
| `micro_bevel` / `no_volume_declared` | 豁免件必须倒角且声明 |

`--selftest` 有 24 条反例，哪条拦不下来就是那条规则没有断言，等于没写。

## 10. 边界

- **不动**：净高 4.9／层高 5.1／板厚 0.2／主柱 0.5／倒角档位／四材质角色／PaletteUV 规则／在役资产运行标高。
- **楼层比例不归本表**：sea 仍守净高与层高契约；"店上居"用立面划分表达，不改层高。
- **分类不受影响**：ρ、倾斜、嵌入都不改 `building_class`；水下观赏楼照样零碰撞零交互。
- **单套件预算不放松**：3000 三角面之类的既有上限照旧。但锥度不花面数，别拿预算当不做锥度的理由。
- 在役资产（阳光房 v008、浮店、霓虹花园）**本次不回改**；新件与新版本按本表。要回改旧资产须单独授权。
