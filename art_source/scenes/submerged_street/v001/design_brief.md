# submerged_street v001 · 设计简报（冻结于建模前）

**任务**：2026-11-02 用户要求，在阳光房周围水下再加十栋独立纯景观建筑，用 Blender 制作并在 Blender 内完成自检。

**参考**：本轮没有附件参考图。视觉真值由两部分构成：① 用户文字清单（十栋的题材与破败程度）；② **阳光房海下基座本身**（`art_source/scenes/bloom_lower_building/v002/`）的实测色彩基调与比例。用户明确"色彩需要统一风格，按照阳光房下方的底座的色彩基调和比例风格"，因此以底座为唯一风格基准，不以想象替代。

## 二、比例基准（从底座实例布局量取）

`bloom_lower_building` 的实例清单 414 条，Z 轴分布给出清晰节拍：楼板在 0 / 1.72 / 3.44 / 5.16 / 6.88 / 8.60 / 10.32，屋面 12.32 → **层高 1.72 源单位、7 层**；运行侧按 2.5/1.5/1.5 适配 → **层高 2.6 米**。窗带自 0.26 起、高约 0.98 源单位 → **窗台 0.4 米、窗高 1.0 米**。

据此本套件默认值（最终游戏米制，一位小数）：

| 项 | 值 | 口径 |
|---|---:|---|
| 层高（楼板顶到楼板顶） | 2.6 | 5.1 米阳光房层高不适用水下街景，此处从底座实测 |
| 楼板 / 屋面板 / 桥面板厚 | 0.2 | 与底座同 |
| 窗台高 / 窗带高 | 0.4 / 1.0 | 窗墙比约 0.38，与底座一致 |
| 窗宽 / 窗间墙 | 1.2 / 0.5 | 节距 1.7 米，楼层 3 开间 |
| 承重柱截面 | 0.4×0.4 | 街景体量小于阳光房主柱，按底座楼体柱比例 |
| 主结构倒角宽 / 段数 | 0.09 / 3 段 | 实体倒角，主体平面保持平 |
| 薄板、板沿倒角 | 0.03 / 2 段 | 不超过板厚 1/2 |
| 细杆（电线、钢筋、栏杆） | 0.008–0.02 / 1 段 | 受截面限制 |

**与 SKILL.md 的关系**：SKILL 的 5.1 米层高、0.5 米主柱是阳光房水上同族的默认值；本条按用户"按底座比例风格"的显式要求改用底座实测节奏，属**登记在案的尺度例外**，不改其他建筑、不改 SKILL 默认值。

## 四、职责与边界

- `building_class = underwater`（水下观赏建筑），全子树纯观赏。
- 不制作碰撞、可走面、泊位、导航障碍、交互点、资源产出、玩法状态、岸线来源；不新增玩法存档字段。
- 无自发光材质（水下街景不做灯，避免与"废弃"叙事冲突，也避免夜间自发亮）。
- 只交付 Blender 源、独立包与 GLB；Godot 接入、碰撞、商业授权与用户最终美术验收另计。
- 麦当劳餐厅保留可辨识的双拱与红黄配色，`license` 记 `trademark_and_reference_pending`。

## 五、验收方式（均在 Blender 内完成）

1. 保存重开后重新核对：组件数、非空几何、原点在底部中心、根与网格变换恒等、Collection 偏移为零。
2. 逐面 PaletteUV：有面积、完整落在单格安全区内（≥8 像素）、活动层与渲染层都是 `PaletteUV`、插值为 `Closest`、图片外链。
3. 材质只允许 `SEA_Matte` / `SEA_Metal` / `SEA_Gloss`，无 `.001` 副本、无废弃材质球。
4. 三角面按实例求值后累计，逐栋断言 ≤ 预算。
5. 真实渲染：每栋 3/4 视角、俯视、关键近景，外加水下背景的整体街区总览，目视检查轮廓、穿插、比例与色彩基调。
