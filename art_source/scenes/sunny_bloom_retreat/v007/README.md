# 太阳能木屋 v007 / 游戏装配 1.4

[海上制作源](sunny_bloom_retreat.blend) · [完整装配](export/v001/placement/solar_cabin/solar_cabin_v1.4.blend) · [独立优化源](export/v001/solar_cabin_optimized_v001.blend)

从用户亲手修改并保存的 v006 派生，保留158个现存集合实例的变换，并将两块实体化的用户木板按实际世界变换纳入组件装配；最终160实例、45种几何组件加4种UV配色变体，共49个可独立打开的组件包。

后区和露台木板轻微错落；浅木/浅沙/暗木不规则交错。前平台珊瑚色与橙红色成组分布，中间一根赭黄；已有平台和桥的错位保留。轮胎悬挂绳延长至两侧栏绳，四个轮胎位置不变。

使用独立公共色板 [sea_cabin_muted_8x8_512.png](../../../shared/palettes/sea_cabin_muted_8x8_512.png)，浅色改暖灰米白，木色降饱和；原公共色板原样保留。底座使用 [bloom_lower_building/v002](../../bloom_lower_building/v002/bloom_lower_building.blend) 的相同配色，几何与原优化GLB一致。

母版仍采用集合实例；修改整个同款组件可切换到“组件母版 | 独立原点”场景选网格，或打开 components 下的独立 .blend。只改一处请先另存再实体化。独立组件文件修改不会自动回写总装。

[交付和当前验证](../../../../docs/development/2026-10-26_solar_cabin_v007.md)。正式游戏路径保持；用户手改的海下基座偏移已保留，并反映到完整装配。
