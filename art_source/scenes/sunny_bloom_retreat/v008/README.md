# 太阳能木屋 v008 / 游戏装配1.5

[海上制作源](sunny_bloom_retreat.blend) · [游戏比例总装](export/v001/placement/solar_cabin/solar_cabin_v1.5.blend) · [独立优化源](export/v001/solar_cabin_optimized_v001.blend)

基于保存的v007继续修改。45种原几何加4种UV配色变体，共49组件、160实例；组件独立包位于components，四分区在modules。

地坪、露台、前平台和桥统一改薄。参考家园补给站浮板厚0.18米，小屋主铺板厚0.22米；后侧较小比例的延伸板约0.18米。木板底保持贴合基座顶面Y=1.16，站立面降至1.38；完整总装包含正式场景的海上/海下变换。

采用[新暖木色板](../../../shared/palettes/sea_cabin_timber_8x8_512.png)，主木色为参考浮板提取的#C49C6E，浅深色轻微交错，前平台不再采用橙红色。保留木板错落、轮胎绳、家具与花草摆位；支撑墙和地面立柱延伸至薄露台底面，避免板变薄后产生悬空间隙。

[完整交付与验证](../../../../docs/development/2026-10-28_thin_cabin_and_dayparts.md)。v007及原色板保留，运行资源沿用原稳定路径。
