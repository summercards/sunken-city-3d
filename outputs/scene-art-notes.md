# 场景结构与生长表现

主要地点与航行区域沿用现有布局，细化由 scene-art.js 负责：

- 圆形屋顶：清晰的花床、十字步道、台阶入口、分段边墙和残窗墙，替换原先遮满结构的彩色球状植被。
- 铁道站台：棚架柱梁、候车凳、边线与楼梯；电车侧窗与门；水下实心基座改为桥墩和横梁。
- 可开发种植园：楼体和屋顶统一尺寸，补齐楼层、窗格、分隔地块和步道。初始可种植地块均为干土。
- 工业楼与断桥：开放残墙、窗洞、缺失屋顶、桥墩、船窗与风中晾衣。
- 周边 11 组废墟：开间残楼、断梁柱架、楼梯残段、缺角楼板四种轮廓，分层楼板与通透空间取代简单整块方塔。这些周边废墟为场景表现；可操作建造沿用木屋、站台、种植园三个既有地点。

建造与种植消费现有 workerMode / jobProgress / level：0–18% 整地并依次铺设修复木板；14–40% 土壤逐渐变湿、喷壶出水；35% 后幼苗错峰萌发并扎根长大；完成后保持湿土和成株。后续升级分别培育第二批地块、电车顶园圃与水道睡莲。已有圆形观赏花园保留成熟植物。

动态包括植株与藤蔓摆动、风车旋转、旗布变形、晾衣摆动、水流变形与漂叶浮动；沿用小船、飞鸟、鱼群、水母、鲸鱼、瀑布和信号灯动态。浅水透明度和焦散亮度调整以保留水下建筑轮廓。

新增静态构件按父节点与材质合并；动画根节点、独立土壤材质与施工部件保留单独更新。

验证脚本：tests/scene-art-regression.cjs（阶段快照与动态检查）；tests/ui-regression.cjs（实际收取、扣费、建造完成及原 UI 回归）。结果与截图位于 outputs。测试通过浏览器拦截注入临时检查接口，正式源码不暴露测试全局。
