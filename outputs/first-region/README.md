## 北侧海底

- 原盆地约 `y=-75`。北侧岩壁打开，旧海床在 `z=-26` 截止，避免旧平面横穿新增深沟。
- `north-trench.js` 的 `TRENCH_PROFILE` 定义连续海台、陡降断层和深沟；几何与潜水碰撞共用同一高度函数。
- 从 `z=-26` 延伸至 `z=-172`，深沟最低 `y=-225`，比原盆地再下沉 150 米。HUD 深度含海面高度 1.12 米；角色中心最低约 `y=-223.5`，保留身体净空。
- 32 米倾斜海盗帆船位于 `(1, -216, -130)`，实际带三根桅杆与损坏帆面、船舱、炮、索具和海盗旗；船体横倾约 18.3°。船体碰撞按局部分段生成。
- 巨型珊瑚采用鹿角、扇面、波浪盘状三种轮廓，主珊瑚高度 9–24 米，沿两侧围合船体，中央保持下降阅读空间。
- 深海衰减焦散，增加局部青绿与淡紫光；陡坡附近相机会收近，避免镜头穿进海床。
