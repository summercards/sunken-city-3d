# 晴空水巷：极简建筑交互

每个建筑只有一个 44px 热区（36px 图标），建筑模型与图标共享悬停信息和点击处理。没有资源时显示升级箭头：可升级为绿色；余额不足、忙碌或满级时为灰色。有资源时，同位置优先显示贝壳。收取结算后经过 280ms 动画切回箭头，收取后另保留 700ms 防连点窗口，避免连点误触升级。

悬停卡片宽 216px，只保留名称、等级、一行状态。卡片不含按钮，背景为 78% 不透明暖白加轻微模糊；出现使用弹性缩放，消失使用淡出收拢，切换目标也有过渡。屋顶图标具有悬停、按下、收取、模式切换和不可用反馈；金额、目的地菜单与进度也有动画。

移除底部常驻导航、角色状态显示、聚焦按钮与操作提示。通过小船/角色的场景操作菜单选择目的地或聚焦，Escape 和点击空白水面关闭操作。资源余额栏缩为海贝与数字。

图标和卡片在相机与世界矩阵更新后逐帧投影；离开镜头的图标隐藏且不参与键盘导航。卡片不参与指针命中，不会阻挡建筑与图标热区。

验证见 ui-regression-results.json，包含资源与升级的优先顺序、重复点击防护、绿/灰状态、扣费与建造完成、共享悬停、动画进出、相机锚点、目的地入口、390px 窄屏和运行时错误检查。截图为 ui-compact-*.png。

复跑：先在仓库根目录运行 python3 -m http.server 8765，再在可加载 Playwright 的 Node 环境执行 node tests/ui-regression.cjs。可通过 APP_URL、CHROME_BIN 指定地址与 Chrome。测试只在浏览器拦截响应中注入检查接口，正式源码不暴露测试状态。
