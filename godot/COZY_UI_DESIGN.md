# 慢节奏休闲界面视觉规范

2026-10-22，第一版已接入。保留点击优先操作，重点统一色彩、体量、反馈节奏。

## 视觉方向

奶油色卡片、彩色圆角按钮、柔软投影和深色正文。以明亮但不刺眼的配色融入现有风格化海岛；不再用深蓝透明底和细霓虹边线表达常规操作。

| 角色 | 色值 | 使用 |
|---|---|---|
| 奶油底 | #FFF7E7 | 管理面板、提示、动作卡片 |
| 深色正文 | #28434F | 正文和按钮文字 |
| 薄荷绿 | #92DFB1 | 种植、补给、农产品、生长进度 |
| 珊瑚橙 | #FFA083 | 常规行动、前往 |
| 奶黄 | #FFD472 | 建造、购买、完成反馈 |
| 天空蓝 | #95D9F4 | 潜水、深度、视角 |
| 浅紫 | #D2BDF2 | 休息、滤镜 |
| 中性米灰 | #EEE6D8 | 关闭、取消 |

共享实现是 `scripts/ui/cozy_ui.gd`。所有现有和动态生成的 Control 接入同一套样式，避免种植页更新后又回到旧风格。颜色不是唯一标识，按钮仍显示动作名称；区域入口由纯图标改为图标加名称。

## 体量与布局

- 面板圆角 22，按钮圆角 18，柔和向下阴影，2 像素奶白边。
- 按钮至少 38 高；正文至少 13、按钮至少 14（Godot 设计坐标，随视口统一缩放）。
- 种植管理卡片扩宽，滚动区增高；刷新时先移除旧行，避免临时重复内容挤动滚动位置或影响按钮命中。
- 动作反馈从细仪表条改为下方独立圆角卡片，粗圆进度条；始终保留顶部取消入口。
- 日常提示缩短为操作要点，减少底部键位说明对景色的占用。

## 动效与节奏

| 反馈 | 参数 |
|---|---|
| 鼠标悬停 | 0.24 秒缓动到 1.025 倍 |
| 按下 | 缓动到 0.97 倍，降低阴影 |
| 面板/提示出现 | 从 0.97 倍柔和展开到 1 倍 |
| 常规提示 | 至少停留 3.2 秒，末尾 0.9 秒淡出 |
| 操作完成 | 金色满条 + “完成啦”，停留 1.4 秒 |
| 低氧提示 | 保留警示语义，脉冲频率由 7 降到 2.5 rad/s |

完成反馈中的按钮不可再次触发操作，避免庆祝时误操作邻近目标。正在进行的动作也不让同一个按钮反复重启。

种植动作调整为播种 0.95 秒、浇水 1.25 秒、收获 1.1 秒。角色的劳作动作从交互开始时播放，时长 1.1 秒。日制生长、收益、航行速度和打捞难度不随换肤改变；慢节奏首先体现为清晰、从容的操作反馈，而非把所有等待拉长。

## 范围与验证

已覆盖 HUD、种植/建造/背包、动作提示、悬停、打捞、订单，以及相机/滤镜工具面板。使用 Godot 样式和缓动实现，没有新增位图皮肤、音效或角色模型。

验证采用原有 1395 项规则/点击回归、原生渲染的鼠标种植闭环和界面展示。展示脚本 `tools/capture_cozy_ui.gd` 仅在内存中准备示例作物，不写玩家存档。

实机截图位于 `outputs/cozy-ui-*.png`，动态演示位于 `outputs/cozy-ui-demo.mp4`。桌面尺寸以当前项目 1600×1000 设计视口为基准，已在 1280×800 / 960×600 窗口观察；没有新增移动端适配。

本次验收：1395 项检查通过；调整布局后，原生渲染的鼠标种植闭环再次完整通过，0 失败。展示录像为正常 Metal 渲染的 301 帧 / 30 FPS（约 10 秒），包含菜单、操作进度、完成反馈和打捞界面。
