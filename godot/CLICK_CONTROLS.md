# 点击优先交互规范与实现

2026-10-22。现有玩法统一提供鼠标入口，键盘保留为快捷操作。点击、长按收线、拖动镜头和滚轮缩放都属于鼠标操作；本次没有加入触屏适配。

## 玩家操作

| 意图 | 鼠标操作 | 结果 |
|---|---|---|
| 行走 | 点击可达地面 | 沿地面路线前往，显示落点环 |
| 航行 | 点击水面、泊位或底部区域按钮 | 岸上先走回上岸点登船，再航行；途中可改道 |
| 上下船 | 点击当前已经靠泊的泊位 | 船上走到上岸点，岸上走回泊位登船；船离开后点原泊位会返航 |
| 采集、种植、建造、打开订单板/绞盘 | 点击世界目标；近处也可点底部“操作” | 自动走近并执行一次，有动作进度；不能执行时说明原因 |
| 种植管理 | 顶部“种植” | 买种、选作物、补水、休息、出售；点地格行前往操作 |
| 建造管理 | 顶部“建造” → 前往 | 自动走近建造牌并交付，材料不足提前提示；跨区域需先前往 |
| 捞漂流物、捕鱼 | 点击对应目标 | 航行到目标附近并采集；新目标替换原任务 |
| 停止动作 | 顶部“取消” | 清除步行、待执行交互、待拾取物、航行或潜水搜索；打捞/订单打开时先退出该面板 |
| 潜水 | 右下“潜水” | 进入海底；航行中需先停船 |
| 游动 | 点击水域 | 在当前深度规划路线；障碍位置拒绝并提示 |
| 改变深度 | “上游 3 米”/“下游 3 米” | 规划到相应高度，受水域边界和障碍限制 |
| 搜索宝箱 | 点击已发现宝箱标签 | 游近后自动搜索；途中不会提前丢掉搜索目标 |
| 头灯/返回水面 | 头灯开关 / 右下“上浮” | 立即切换头灯，或执行返回水面流程 |
| 打捞 | 点击停钩，按住收线，松开放线 | 张力条持续反馈；按钮外松手也停止收线；可直接退出 |
| 存取档 | 顶部“保存”/“读档” | 沿用原槽位和规则，显示成功或失败反馈；潜水时禁用 |
| 镜头 | 拖动、右键旋转、滚轮，或顶部“视角” | 相机面板可点预设、调滑杆、关闭 |
| 滤镜 | 顶部“滤镜” | 调整现有参数，关闭按钮可退出 |

## 一致性规则

1. **一次点击只执行一次。** 播种后不擅自连浇，相邻格不抢选定目标，完成后关闭自动交互。
2. **取消清理整个任务。** 不只藏掉提示，还清理路径、到达回调、自动按住状态、待拾取物和潜水搜索，避免取消后又触发旧动作。
3. **菜单不穿透。** 背包、种植、建造、订单、打捞、相机和滤镜面板打开时，不把未被控件消费的点击解释为世界目标；菜单期间不执行岸上交互。打开物资类页面会取消待执行的自动交互，但已有行走/航行可以到达终点。
4. **重新命中释放位置。** 世界点击在鼠标释放点重新选择目标，不沿用上一帧悬停；按下必须发生在世界里。拖出阈值后再拖回起点仍算拖动。
5. **无法执行时不要绕路。** 缺种子、缺水、材料不足、未解锁等先报原因；进入动作后条件改变导致失败，也终止自动重试。
6. **反馈有层次。** 悬停显示名称、动作或阻挡原因；接受点击显示前往提示和落点；执行用已有进度条；完成显示产物/结果。复杂动作保留合理耗时，免去必须记住键位的门槛。
7. **不远程改写区域规则。** 跨岛种植或建造仍须航行并上岸；点菜单不会瞬移或远程收获。

## 实现位置

- `scripts/main.gd`：统一按钮命令、任务取消、点击归属、菜单隔离、导航与交互。
- `scripts/hud.gd`：直接入口、关闭按钮、潜水深度和头灯按钮、点击提示。
- `scripts/ui/hover_card.gd`、`interact_prompt.gd`：可点击目标说明和近处操作按钮。
- `scripts/ui/salvage_panel.gd`：鼠标按住/松开和退出；窗口失焦也清除鼠标收线状态。
- `scripts/world/underwater_world.gd`：当前深度点击导航、上下游、取消、自动搜索衔接。
- `scripts/orbit_camera.gd`：面板打开时清理拖动并停止抢输入。

## 验证

- `tests/test_click_controls.gd`：30 项，覆盖入口、取消、无资源即时拒绝、菜单穿透、往返拖动识别、潜水路径与打捞退出。
- `tools/capture_click_controls.gd`：正常 Metal 渲染下派发真实 Viewport 鼠标按下/松开事件，验证工具栏、隔离槽位保存读档、世界第二格命中、取消、下潜、头灯、调深度、上浮及打捞。测试只删除自身创建的隔离测试槽，不改玩家存档。
- `tools/capture_farm_cycle.gd`：重新跑完购买→播种→浇水→休息→收获→出售→再次播种的鼠标闭环。
- 原有种植、地面航行、场景及核心规则套件继续回归。

## 当前边界

海底点击游动采用当前深度的水平平面；垂直高度用按钮调整，尚无三维鼠标自由落点。世界目标仍使用屏幕投影命中，极远镜头下密集对象建议拉近或从管理页选择。没有新增音效、独立工具模型或触屏手势；保留原有视觉进度与动画。

本次结果：点击专项 30 项、原有回归 1365 项全部通过；正常渲染的点击操作测试和种植闭环测试均为 0 失败。统一运行 `bash godot/verify_click_controls.sh`；加 `--visual` 可重新运行两套桌面鼠标测试。
